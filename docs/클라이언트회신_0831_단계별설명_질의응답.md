# "단계별 설명" 문서 질의 회신 (2026-08-31)

> 대상 문서: 260821 단계별 설명.hwpx / 코드·데모 출력(demo_output/dfm_demo) 기준으로 수치 재검증함.

## Q1. 방향·κ 정리 — trend/plunge로 κ를 구한 것이 아닌지, DFM의 set·κ를 쓰지 않는 이유

말씀하신 대로입니다. **trend/plunge 각도를 거치지 않고, 절리선별 3차원 패치 법선
(`trace_normal_xyz`, DFM의 3D_disk_data.csv 유래)을 그대로 받아 축성(axial) Fisher
추정으로 평균 pole과 κ를 구합니다.** 결과표의 trend/plunge는 추정된 평균 pole을
보고용으로 각도 변환한 출력일 뿐, 추정 입력이 아닙니다.

DFM 결과를 쓰지 않고 새로 구하는 이유는 세 가지입니다.

1. **DFM의 DS 번호는 막장면별 클러스터 번호라서 전역 절리군이 아닙니다.** 같은 DS 번호가
   면마다 다른 방향군을 가리키므로, 본 파이프라인은 (면, DS)별 평균 법선을 30° 절단
   계층군집으로 **전역 재분류**합니다. 실제 변환 결과(set_mapping.csv)에서 이를 확인할
   수 있습니다.

   - **같은 DS 번호가 면마다 다른 방향군입니다.** 예컨대 DS 1은 면 01·02·08에서는
     전역 set 3, 면 03·04에서는 set 2, 면 05·06·09·10에서는 set 4, 면 07에서는
     set 1로 각각 귀속되었습니다. 즉 "DS 1의 κ"를 구한다 해도 그것은 면마다 서로
     다른 방향군에 대한 값이어서, 어느 절리군의 κ인지 자체가 정의되지 않습니다.
   - **역으로, 하나의 전역 절리군은 여러 면·여러 DS 번호에 흩어져 있습니다.**
     전역 set 1은 12개 면에 걸친 16개 (면, DS) 조합(DS 1~5 혼재)으로 구성되며,
     면 01에서는 DS 3과 DS 4 두 클러스터가 모두 set 1로 합쳐졌습니다(같은 방향군을
     DFM이 한 면 안에서 둘로 쪼갠 경우). 따라서 DFM의 (면, DS)별 κ 중 어느 값도
     전역 set 1이라는 모집단을 대표하지 않습니다.
   - **κ는 면별 값을 평균해서 전역 값으로 만들 수 있는 양이 아닙니다.** Fisher
     집중도는 표본(법선)을 합동(pooling)해서만 재추정할 수 있습니다. 또한 면별 κ는
     그 면 안에서의 산포만 반영하고 면과 면 사이의 평균 방향 변동이 빠져 있으므로,
     이를 어떻게 조합하더라도 전역 절리군의 산포를 체계적으로 과소평가(κ 과대)하게
     됩니다. 결국 재분류된 set 기준으로 전체 법선을 모아 κ를 새로 추정하는 것이
     유일하게 정합적인 방법입니다.
2. **좌표 보정 이후의 일관성**: 변환 단계에서 터널축을 x축에 정렬하는 전역 회전을
   적용합니다. κ 자체는 회전 불변이지만 평균 pole 방향은 좌표계에 종속되므로, 회전된
   좌표계·재분류된 set 기준으로 법선에서 다시 추정하는 것이 일관됩니다.
3. **자기완결성**: 이 κ는 P32 환산계수 C = E[sinφ]의 Fisher 구적과 조건부 생성의
   법선 표본추출에 직접 들어갑니다. 역산에 쓰는 법선·set 정의와 동일한 소스에서 κ를
   구성해야 외부 값과의 정의 불일치 위험이 없습니다.

## Q2. 절리선 개수 산정 — 6,259 / 1,658 / 4,601 / 255 / 295

개수 인식은 대체로 맞고, 한 가지만 정정 드립니다.

- 유효 절리선 6,259개(= 2,293+1,664+1,602+700, 절리군 1~4) 맞습니다. 전체 6,447개 중
  표본 부족으로 제외한 절리군 5·6의 188개를 뺀 값입니다.
- **1,658개는 "미재현"이 아닙니다.** 6,259개 절리선 전부가 복원에 사용되며, 응집
  연결(agglomerative association)이 같은 균열에서 왔다고 판정된 절리선 여러 개를
  원판 1개로 묶기 때문에 원판 수가 4,601개가 된 것입니다. 즉 1,658 = 6,259 − 4,601은
  **병합에 의한 감소분**입니다. (검증: 복원 CSV에서 원판별 n_traces 합 = 정확히 6,259)
  문서의 "재현율 약 85%"는 별개의 사후 진단 지표로, 복원 원판을 실측 막장면 평면으로
  다시 잘라 관측 절리선과 현(chord)이 일치하는 비율입니다.
- 이때 병합은 면 간 연결만이 아닙니다. 감소분 1,658의 내역은 다음과 같습니다.
  - **같은 막장면 안에서의 병합: 878개** — 단일 면 위의 절리선 2개 이상을 묶은
    원판이 610개(절리선 1,488개 흡수)입니다. 하나의 균열이 거친 막장면 위에서
    끊어진 여러 세그먼트로 매핑된 경우, 공면·근접 조건(법선각 ≤15°, 공면 잔차
    ≤0.15 m, 중심거리 ≤3.5 m)을 만족하는 절리선들이 같은 면 안에서도 한 원판으로
    합쳐집니다.
  - **여러 막장면에 걸친 병합: 780개** — 다면 관통 원판 255개가 절리선 1,035개를
    흡수했습니다.
- 여러 막장면 관통 원판 255개의 내역: **2개 면 관통 233개, 3개 면 20개, 4개 면 2개.**
  추측하신 대로 대부분 2개 면입니다.
- **원적합 295개의 방법**: 절리선 끝점이 관측창(막장면 convex hull) 경계에서 0.15 m
  이상 떨어진 안쪽에서 끝나면, 관측창에 잘린 것이 아니라 **실제 균열 경계점**으로
  분류됩니다(disc_boundary). 한 원판(연결된 절리선 묶음)에 이런 경계점이 **3개 이상**
  모이면 이를 원판 평면에 투영해 원 적합(Kåsa fit)을 수행하고, ① 경계점들이 덮는 호
  ≥ 120°, ② 적합 잔차 ≤ 0.2 m, ③ 반지름 ≥ 0.3 m를 모두 만족할 때만 반지름을
  "확정(determined)"으로 채택합니다. 이 조건을 통과한 원판이 295개이고, 나머지
  4,306개는 경계 증거가 부족하여 k_r 기반 사후분포 표본(--radius-mode sample)으로
  반지름을 부여했습니다. 참고로 255(다면 관통)와 295(원적합)는 서로 다른 속성의
  분류라서 배타적 범주가 아니며 일부 겹칠 수 있습니다.

## Q3. LOFO의 위치

네, 맞습니다. **LOFO는 순수 검증(외삽 성능 정량화) 단계이며, DFN 구성에는 관여하지
않습니다.** [7]의 최종 JSON 생성은 LOFO 출력을 전혀 읽지 않으므로 생략해도 결과가
동일합니다. 현 데이터에서는 절리 대표 규모(반지름 중앙값 ~0.27 m)가 막장면 간격
(1.3~2.9 m)보다 훨씬 작아 재현율이 0~1%로 나오며, 이는 알고리즘 실패가 아니라 관측
기하의 한계라는 점을 문서에 기록하기 위해 수행한 것입니다.

## Q4. 조건부 암반균열망의 백만 개 — 숫자의 의미, 축소 가능 여부, [6] 단계의 존재 이유

**백만 개는 선택한 숫자가 아니라 역산 결과가 결정하는 숫자입니다.** 생성 개수 N은
역산된 P32(절리군 합 ~6.1 m²/m³), 크기분포(k_r ≈ 3.9로 소형 균열 우세), 생성 박스
부피 V로부터 N = f(P32, 크기분포, V)로 산출됩니다. 같은 부피에서 개수만 1만 개로
줄이면 P32가 목표의 1/100이 되어 균열망 밀도 자체가 왜곡되므로, **개수는 자유
파라미터가 아닙니다.** 소형 균열(0.5 m급)이 지배적인 이 현장 특성상 P32를 채우는 데
많은 원판이 필요한 것입니다.

다만 두 가지를 구분해 주시면 됩니다.

- **최종 해석 입력은 백만 개가 아닙니다.** [7]에서 해석 도메인(마지막 막장면 전방
  10 m + 단면 halo 5 m)과 교차하는 원판만 남긴 약 1.96만 개(예시 실행 기준,
  observed 183 + unobserved 19,434)가 JSON으로 나갑니다.
- **[6]은 [7]의 입력이 아니라 검증·진단 단계입니다.** [7]은 [6]의 출력을 읽지 않고
  동일한 생성·조건화 함수를 내부에서 다시 호출합니다(같은 seed면 동일 결과). [6]을
  별도로 두는 이유는, 관측 막장면 전 구간을 덮는 조건부 균열망을 만들어 "관측
  절리선 통계(P21, 길이분포, κ)를 재현하는가"를 관측과 직접 대조 검증하기
  위해서입니다(observed vs conditioned 그림, P21/P32 진단 출력). **최종 JSON만
  필요하면 [6]은 생략 가능합니다.**

"막장면 전방 해석 도메인 내에서만 생성하면 되지 않는가"에 대해서는 — **[7]이 실제로
그렇게 동작합니다.** [7]의 생성 박스는 해석 도메인에 마진(= --rmax-local, 기본 25 m)을
더한 범위로 국한됩니다. 마진이 필요한 이유는 ① 중심이 도메인 밖에 있어도 반지름이
큰 원판은 도메인을 관통할 수 있어, 마진 없이 생성하면 도메인 경계부 P32가
과소평가되고(경계 효과), ② 부재 조건화(관측 막장면에 0.5 m 이상 절리선을 남겼어야
하는데 관측되지 않은 원판 제거)를 위해 관측 막장면과의 교차 검사가 가능해야 하기
때문입니다.

**계산량을 줄이고 싶다면** 개수 직접 지정 대신 `--rmax-local`을 낮추는 것이
정당한 방법입니다(예: 25 → 10~15 m). k_r ≈ 3.9에서는 10 m 이상 대형 원판이 극히
희소하여 결과 영향은 미미한 반면, 생성 박스와 N이 크게 줄어듭니다.

## Q5. 막장면 4개만으로 전방 DFN 구성 — 폴더 4개만 남기면 되는지

면 개수가 하드코딩되어 있지 않습니다. **원본은 그대로 두고 DFM_Export 사본 폴더에
원하는 4개 면 폴더만 남긴 뒤 `--dfm-dir`을 그 사본으로 지정**하면, 이후 [1]~[7]
명령은 동일하게 동작합니다.

다만 다음을 유의해 주십시오.

1. **절리군 재분류가 4개 면 기준으로 다시 수행**되므로 전역 set 번호·개수가 12면

   4개 면에서만 관측되던 막장면 평행군(set 4)은 어느 4개 면을 고르느냐에 따라

3. 해석 도메인의 시작 x는 포함된 면 중 마지막 면이 됩니다.
4. 부수 효과로, **앞쪽 4개 면만 사용해 전방을 예측하고 뒤 8개 면의 실측 절리선을
   참값으로 대조하는 블라인드 검증**이 가능해집니다. 예측 성능을 정량 평가할 좋은
   실험이므로 원하시면 함께 수행해 드리겠습니다.

## R1. DS와 set이 왜 다른가

DFM은 **막장면 하나하나를 독립적으로 클러스터링**합니다. 각 면에서 그 면에 보이는
절리선들만으로 방향군을 나누고 번호를 새로 매기므로, DS 번호는 면 내부에서만 의미가
있는 인덱스입니다(크기순 번호도 아님 — 예: 면 01에서 DS 1=122개 < DS 2=165개 < DS 3=178개).
면과 면 사이에 "DS 1 = 같은 방향군"이라는 대응을 만들어 주는 정보가 DFM 출력에
존재하지 않습니다. 반면 역산은 전체 터널 구간에서 하나의 절리군 모집단(방향분포·크기
분포·P32)을 추정해야 하므로, 모든 면의 법선을 방향 공간에서 한꺼번에 군집화하는
전역 재분류가 필요합니다. DS는 "이 면에서 몇 번째 방향 무리인가", set은 "터널 전체에서
어느 절리군인가"라는 서로 다른 질문에 대한 답입니다.

## R2. 백만 개 생성의 효율화 방안 (실험 결과)

생성 개수는 P32×부피의 함수라 개수 자체는 줄일 수 없지만, **생성 부피와 크기 하한은
줄일 수 있습니다.** 실험으로 확인한 결과:

- **`--rmax-local` 25 → 10 m**: 생성 1,122,258개 → **183,708개 (6.1배 감소)**,
  도메인 결과는 19,617 → 19,594개로 사실상 동일(반지름 중앙값 0.608→0.606 m,
  p95 1.174→1.165 m). 생성 박스 마진이 rmax에 비례하기 때문이며, 관측상 10 m급
  대형 균열의 증거가 없는 본 데이터에서는 손실이 거의 없습니다.
- **크기 하한 상향(대형 구간만 생성)**: 도메인 내 19,617개 중 r≥1 m는 1,759개(9.0%),
  r≥2 m는 140개(0.7%), r≥3 m는 35개(0.2%)입니다. 안정성 해석이 상위 20~30개
  대형 균열만 사용한다면, P32를 크기 구간으로 분할해 대형 구간만 생성하는 방식으로
  수백~수천 배 절감이 가능합니다. 단, 블록 형성에는 소형 균열 간 교차도 기여하므로
  해석 방법이 실제로 무엇을 입력으로 받는지에 맞춰 결정해야 합니다.

## R5. 랜덤 시드 민감도 (seed 2026 / 7 / 123 실험 결과)

- **모집단 통계는 시드 불변입니다**: 도메인 내 개수 19,393~19,617개, 반지름 중앙값

  9.2 / 21.2 / 17.7 m로 2배 이상 차이 나고, 상위 30개끼리 위치를 대조하면

  분입니다(관측 복원 균열의 최대 반지름은 ~1.5 m). 총 균열 면적도 꼬리 때문에

  ③ 시드별 실현을 블록 판정까지 돌려 민감도를 정량화. ③은 블록 탐지 파이프라인
  연계가 필요하며 후속 작업으로 수행 가능합니다.
