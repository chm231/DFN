  배율 p90 1.93·최대 6.25, 증가 p90 0.51m·최대 2.63m. 전체 shrinkage 평균

  있음(현행 조각-최대-현은 이 오류에 둔감).

### 7-1. 구현 + 검증 (사용자 "해봐")
- 구현: `reconstruct(..., lower_bound="fragment"|"span")` + CLI `--lower-bound`
  (reconstruct·validate_reconstruction_lofo 양쪽). fragment 분기는 기존 코드 라인
  그대로 → 기본값 회귀 안전(py_compile OK). span은 (cluster,face) 끝-끝 스팬 사용.
- **LOFO 검증 무검정력 판명**: 1-6면(세트 1-3) fragment/span 둘 다 hold-out 면
  예측 chord **0개** → recall 0%, precision nan. 원인: 이 창의 복원 disc는 전부
  단일면 소형(다면 관통 0개, 반지름 평균 0.55m). 면 간격 ~1.85-2.3m라 자기 면을
  빼면 어떤 disc도 그 면에 닿지 못함(= 이미 설명한 "위치 예측력 없음"과 동일).
- 직접 확인: 이웃 면에 ≥0.5m 현을 남기는 disc가 fragment 1개 / span 1개 — span의
  반지름 증가(실변화 117개, 최대 +2.63m)로도 면 간격을 못 넘어 관측 가능한
  예측 차이가 생기지 않음. 두 정의는 이 데이터로 판별 불가.
- **결론**: 프로젝트 데이터는 실측이라 참 반지름 GT가 없고, 유일한 관측 검증(LOFO)은
  면간 예측력 부재로 무검정력 → span 우월성 입증 경로 없음. 코드는 플래그로
  보존(기본 fragment 유지, 보수적). 채택 검증하려면 참 반지름 아는 합성 DFN 또는
  면 간격이 disc 크기 대비 촘촘한 데이터 필요. 벽면 절리선 데이터 확보 시 재검토.

## 7-4. 세트별 적응 max_sep 구현 (사용자 통찰: 방향 편향)
- 사용자 통찰: 막장면과 평행한 절리군일수록 두 막장면 사이 현이 멀리 떨어져
  나타남 → 고정 max_sep는 막장면 평행 원판을 과소 매칭(방향 편향).
- 이론 확인: 두 현 중심거리 = Δx/sinθ = Δx/√(1−nx²) (θ=원판법선-x축각).
  nx→1(막장면 평행) 발산. 실측: 4.5가 놓친 다면 |nx| 0.74 > 잡은 것 0.70.
- 구현: associate_agglomerative + reconstruct CLI `--adaptive-sep` (기본 off,
  회귀 안전). 게이트 = clamp(sep_safety·Δface_x/sinθ, same_face, sep_cap),
  단 Δface_x > adjacent_dx_max(3.2m)면 skip(비인접 원천 차단). 파라미터
  --sep-safety(1.4) --sep-cap(8.0). py_compile OK.
- **검증 (1-6면, 고정4.5 vs 적응k1.4)**:
  | | 다면 | 비인접 | 면5-6 | 막장면평행(|nx|≥0.8) | 스팬p90 |
  |---|---|---|---|---|---|
  | 고정 4.5 | 280 | 0 | 41 | 36 | 7.2m |
  | 적응 k1.4 | 308 | **0** | 60 | **58** | 7.1m |
  | 적응 k1.6 | 340 | 0 | 64 | 67 | 7.4m |
- **방향 편향 감소 확인** (docs/figures/adaptive_sep_direction_bias.png):
  막장면평행 원판 비율 — 모집단 26.9% / 고정 12.9% / **적응 18.8%** (모집단에
  근접). 다면 평균 |nx| 편차 고정 −0.014 → 적응 +0.006. 즉 적응이 매칭된 원판의
  방향분포를 실제 절리 모집단에 더 가깝게 만듦(편향 완화). 비인접 과병합은 0 유지.
- **함의**: 현재 데이터는 세트 3개 방향이 비슷(|nx| 0.68~0.74)해 편향이 크지 않지만,
  막장면 평행 세트가 지배적인 현장에선 적응이 필수. 옵션으로 보존(기본 off) —
  채택 시 파이프라인에 --adaptive-sep 추가하면 됨. 미채택(재생성엔 미적용).
