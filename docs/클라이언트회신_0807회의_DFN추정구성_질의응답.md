## 1) 관측 균열 복원에서 사용한 lower bound의 근거

복원 단계에서 말씀드린 하한 $r_{obs}$는 **통계적 가정이 아니라 순수 기하학적 제약**입니다.

- 막장면에서 관측된 절리선은 3차원 원판형 균열이 막장면과 만나 생긴 **현(chord)** 입니다.
- 어떤 원판이 이 현을 포함하려면, 원판 반지름은 최소한 "적합된 중심에서 관측점까지의 최대 거리" 이상이어야 합니다(식 6.54):

$$r_{obs} = \max_i \lVert p_i - c \rVert$$

  관측점만으로 중심을 정할 수 없는 일반적인 경우에는 **관측된 최대 현길이의 절반**이 직접 확인 가능한 하한이 됩니다. 길이 $\ell$인 현은 반지름 $\ell/2$ 미만의 원판 안에 기하학적으로 존재할 수 없기 때문입니다.

이 값을 "하한"으로만 취급하고 반지름 추정값으로 쓰지 않는 이유는 두 가지입니다.

1. 관측된 현은 일반적으로 지름이 아니라 **임의 위치에서 잘린 현**이므로, $r_{obs}$를 그대로 쓰면 반지름이 체계적으로 과소평가됩니다.
2. 절리선 자체가 터널 단면 경계에서 절단된 경우 관측 현길이는 실제 현길이보다도 짧습니다.

따라서 복원 반지름은 다음 계층으로 결정합니다(표 6-3).

| 방식 | 반지름 결정 | 근거 강도 | 검증 사례 개수 |
|---|---|---|---|
| determined | 경계점 원 적합 (Kåsa) — 경계점 3개 이상, 원주 피복각·잔차 기준 통과 시 | 직접 측정 | 48 |
| shrinkage | $r \ge r_{obs}$ 조건 하에서 절리군 멱법칙 분포($k_r$)를 사전분포로 한 경험적 베이즈 사후평균 | 통계적 추정 | 329 (약 79%) |
| lower_bound | 절리군 모집단 정보가 없어 축소추정 불가 시 $r_{obs}$만 부여 | 하한값만 확인 | 41 |

즉 lower bound는 "관측자료가 보증하는 최소값"이고, 최종 반지름은 어떤 경우에도 $r_{obs}$보다 작아지지 않도록 제약하되, 가능한 경우 절리군 반지름 분포로 보정(shrinkage)하여 과소평가를 방지합니다.

## 2) sin φ를 분모에 넣은 것의 의미

$P_{32}$ 산정식에서 sin φ가 분모에 들어가는 것(식 6.47)은 **막장면 관측의 방향 표본편향(orientation sampling bias)을 제거하는 보정**입니다. 시추공 조사에서 쓰는 Terzaghi 보정과 같은 원리를 면적 기준($P_{21} \to P_{32}$)으로 확장한 것입니다.

유도 논리는 다음과 같습니다 (식 6.48~6.49).

- $\varphi$ = 절리면과 막장면이 이루는 각. 반지름 $r$인 균열 원판이 막장면($x=\text{const}$)과 교차할 수 있으려면 중심이 축방향 폭 $2r\sin\varphi$ 안에 있어야 합니다.
- 즉 **막장면에 절리선을 남길 확률 자체가 sin φ에 비례**합니다.
  - 막장면과 평행한 절리군(sin φ ≈ 0): 실제로 존재해도 절리선을 거의 남기지 못함 → 관측 $P_{21}$이 실제 강도를 크게 과소반영
  - 막장면과 수직인 절리군(sin φ ≈ 1): 거의 온전히 관측됨
- 중심이 공간적으로 균일 분포하면 기대 관측강도는 $E[P_{21}] = C \cdot P_{32}$, $C = E[\sin\varphi]$ (절리군 방향분포에 대한 기댓값, 식 6.49)가 되고, 따라서 역산은

$$\hat{P}_{32} = \frac{P_{21,obs}}{C}$$

  로 **분모에 sin φ(의 기댓값)가 들어갑니다.** "덜 보이는 절리군일수록 관측값을 더 크게 되돌려 준다"는 의미입니다.

부가적으로 두 가지를 말씀드립니다.

- 교차 가능 폭과 기대 현길이는 각각 $r$에 비례하고 균열 면적은 $r^2$에 비례하므로, $P_{21}/P_{32}$ 비에서 반지름 의존성이 상쇄되어 **$C$는 반지름 분포와 무관하게 방향분포만으로 결정**됩니다. 벤치마크의 절리군별 값은 $C$ = 0.828 / 0.314 / 0.789 / 0.597 (Set 1/2/3/5)입니다. 예컨대 Set 2는 막장면에 잘 드러나지 않는 방향이어서(C=0.314), 실제 3차원 강도가 막장면 관측 강도의 약 3.2배로 환산됩니다.
- 이 해석식은 무한 관측면 가정에서 유도되므로, 유한 관측창·최소 검출길이의 영향은 순방향 모사로 별도 검증했고($\eta_{det}$, 식 6.52), 벤치마크에서는 해석식 대비 차이가 약 2% 이내였습니다.

## 3) Set 4처럼 멱법칙을 따르지 않는 절리군 — reject인가, 강제 fitting인가

결론부터 말씀드리면 **둘 다 아니며, "자료는 유지하되 멱법칙 외삽만 하지 않는" 제3의 처리를 했습니다.** 그리고 실제 현장 적용에서는 분포족 자체를 교체하는 것이 원칙적 대응입니다.

**(1) 벤치마크에서 Set 4를 제외한 것은 자료 reject가 아닙니다.**
Laxemar 벤치마크에서 Set 4는 참값 정의 자체가 멱법칙이 아닌 **지수분포**입니다(Munier, 2006). 멱법칙 지수 $k_r$의 역산 정확도를 검증하는 절에서 참값이 멱법칙이 아닌 절리군을 비교 대상에 넣는 것은 검증 설계상 무의미하므로 **$k_r$·$P_{32}$ 검증 대상에서만** 제외한 것입니다. Set 4의 관측 절리선 자체는 버리지 않았습니다 — 전처리·평면 적합·복원을 동일하게 거치며, 복원 계층에서 lower_bound로 분류된 41개가 모두 Set 4입니다(표 6-3). 즉 관측된 균열은 조건부 균열망에 그대로 포함됩니다.

**(2) 강제로 멱법칙 fitting한 값을 쓰는 것은 권장하지 않습니다.**
이유는 세 가지입니다.

- 본 추정의 우도(가시길이 + 절단등급 결합 우도)는 절단 멱법칙 분포족을 전제로 유도되어 있습니다. 분포족이 틀리면 $k_r$ 추정치는 정의상 의미를 잃고, 그 $k_r$로 수행하는 shrinkage 반지름 보정과 미관측 영역 확률 생성까지 편향이 전파됩니다.
- 지수분포는 멱법칙과 꼬리 거동이 근본적으로 다르므로(대형 균열 빈도), 강제 적합 시 특히 대형 균열 외삽에서 오차가 큽니다.
- 강제 적합의 오차는 채택등급 판정만으로는 걸러지지 않을 수 있습니다.

**(3) 현장 적용 시 원칙적 대응: 적합 진단 후 분포족 교체.**
실제 현장자료는 참 분포를 모르므로 다음 절차를 권장하며, 본 프레임워크는 이를 수용할 수 있는 구조입니다.

1. **적합 진단**: 순방향 모사 검증(추정된 파라미터로 가상 절리선을 생성해 가시길이·절단등급 분포를 관측과 비교)과 Kaplan–Meier 생존곡선 보조 진단이 이미 파이프라인에 포함되어 있습니다. 멱법칙이 맞지 않는 절리군은 이 단계에서 계통적 불일치로 드러납니다.
2. **분포족 교체**: 우도의 구성 요소 중 관측창 절단 커널·절단등급 분류는 반지름 분포족과 무관하므로, 참 현길이 분포 부분만 지수·로그정규 등 대안 분포족으로 바꿔 동일한 최대우도 절차를 적용할 수 있습니다. 분포족 간 비교는 동일 우도 기준(AIC 등)으로 수행합니다.
3. **$P_{32}$ 환산은 영향 없음**: 위 2)에서 설명했듯 보정계수 $C$는 반지름 분포와 무관하게 방향분포만으로 결정되므로, 분포족을 교체해도 $P_{21} \to P_{32}$ 환산 절차는 그대로 유효합니다.

요약하면 — 벤치마크에서는 참 분포를 알고 있었기에 검증 대상에서만 제외하고 관측 균열은 하한값 부여로 보존했으며, 현장에서는 "reject도 강제 fitting도 아닌, 진단 후 분포족 교체"가 본 방법론의 의도된 확장 경로입니다.
