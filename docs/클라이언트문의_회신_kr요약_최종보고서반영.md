# 회신 — 정리해 주신 k_r 추정 요약 슬라이드의 최종보고서 반영 사항

(식 번호는 **최종보고서(2026-07 최종본) 제6장** 기준)

정리해 주신 슬라이드는 종전 보고서의 방식(절리군별 ℓ_min,fit 후보 탐색 + k_r 후보마다
가상 절리선을 새로 생성하는 순방향 MC 우도)을 정확히 요약한 것입니다. 최종보고서에서는
이 절차가 **하이브리드 우도**(제3절 2항, 식 6.30–6.45)로 개편되어, 아래 항목들이
바뀝니다.

큰 그림은 두 가지입니다.

1. **ℓ_min,fit 선택 절차가 없어졌습니다.** 후보군(0.2–0.7)을 두고 고르는 대신, 모든
   절리군에 **0.5 m를 공통 고정**합니다. 선택 절차 자체가 추정 결과에 영향을 줄 수
   있고, 특히 벤치마크 참값을 참고해 고르면 검증의 독립성이 훼손되기 때문입니다
   (제3절 2.4).
2. **k_r 후보마다 가상 절리선을 다시 만들지 않습니다.** 우도를 k_r에 의존하는 부분과
   의존하지 않는 부분으로 분리합니다. k_r 의존부(반지름 분포 → 참 현길이 분포)는
   **닫힌형 해석식**(식 6.34–6.37)으로 계산하고, k_r 무관부(터널 단면 다각형 절단·
   절단등급 분류·적합 하한 적용)는 **창·절단 커널**(식 6.38)로 절리군별 **1회만**
   수치 모사한 뒤 모든 k_r 후보에 재사용합니다(제3절 2.3). 슬라이드 오른쪽 상자의
   절차는 이 "커널 1회 계산"의 내용으로 흡수됩니다.

## 왼쪽 상자 (k_r 추정 절차) — 항목별

| 슬라이드 항목 | 판정 | 최종보고서 기준 |
|---|---|---|
| 1. ℓ_min_fit 후보군 (0.2–0.7) | **삭제** | 전 절리군 공통 **0.5 m 고정** (제3절 2.4) |
| 1. k_r 후보군 (1–5) | **수정** | 격자 **{1.50, 1.55, …, 5.50}** (0.05 간격, 81점 — 식 6.42) |
| 2. "ℓ_min_fit 하나 가정 후 k_r,max 선정" | **수정** | 고정 ℓ_min,fit 하나에 대해서만 프로파일 우도곡선을 만들고 k̂_r = argmax logL (식 6.43) |
| 2-1. histogram (bin 0.1–0.3, 구간 일치) | **수정** | 가시길이를 **적합 하한–관측 최대길이의 로그 등간격 40구간** × 절단등급 3종으로 집계. "관측 분할표와 모형 확률표에 공통 구간 경계" 원칙은 그대로 유지 |
| 2-2. 관측 도수 n_i,c / 가상 상대도수 p_i,c | **구조 변경** | n_i,c는 동일(단순 도수, 식 6.40). p_i,c는 가상 trace 히스토그램이 아니라 **해석식 현길이 확률질량 w_j(k_r)(식 6.37) × 창·절단 커널 K_jic(식 6.38)의 결합**으로 계산하고 전체 셀 합으로 정규화 (식 6.39) |
| 2-3. logL = Σ n_i,c log p_i,c | **유지** | 동일한 다항 로그우도 (식 6.41 — 0 방지용 ε 하한만 추가) |
| 3. "k_r,max 변화가 크지 않은 최대 ℓ_min_fit과 0.3 중에 선정" | **삭제** | 선택 절차 폐지 (0.5 m 고정으로 대체) |
| 4. 결과물 | **보강** | ① 프로파일 우도 + **ΔlogL ≤ 2 지지구간**(식 6.44), ② 절리선 재표집 bootstrap **95% 신뢰구간**(두 구간은 산정 방법이 달라 구분 표기), ③ 절리군별 요약값, ④ 사후예측 진단. "ℓ_min,fit별 적합 결과" 산출물은 없어짐 |
| 4. "사후예측: forward MC를 다시 수행" | **수정** | MC 재수행이 아니라 **추정된 k̂_r의 해석식 확률질량(식 6.37)을 기존 커널(식 6.38)과 재결합**해 (ℓ_vis, c) 분포를 만들고 관측 분포(절단등급 구성비 포함)와 대조 (제3절 2.4) |
| 식 6.3 (절단 멱법칙 pdf) | **수정** | 최종보고서 식 6.31: 하한이 절리군별 **유효 하한 r_min,k^eff = max(전역 하한, r_0,k)** (식 6.45)인 형태로 정의 |

## 오른쪽 상자 (가상 trace 생성) — 항목별

이 절차 전체가 "k_r 후보마다 반복"에서 "**절리군별 1회 계산하는 창·절단 커널**"로
바뀝니다. 커널 사양: 참 현길이 [ℓ_min,fit, 2r_max]를 **로그 등간격 64구간**으로 나누고
구간당 **3,000표본** (제3절 2.3).

| 슬라이드 항목 | 판정 | 최종보고서 기준 |
|---|---|---|
| 1. U 난수 사용 원칙 | **유지** | 커널 표집에도 동일 |
| 2. 반지름 표집 (r_PL 역변환식) | **k_r 우도에서 삭제** | 커널은 반지름을 표집하지 않음. 반지름→현길이 관계는 해석식 3종 — 교차 조건부 현길이 f_ℓ(ℓ\|r) = ℓ/(4r√(r²−(ℓ/2)²)) (식 6.34), 크기편향 g_R ∝ r·f_R (식 6.35), 이를 적분한 f_ℓ(ℓ\|k_r) (식 6.36) — 으로 대체. (역변환 표집식 자체는 DFN **생성** 단계용으로 제1절 2.1.3 식 6.6에 그대로 남음) |
| 3. Fisher 방향 표집 (θ, plunge, trend) | **수정** | 커널에서는 3차원 방향을 Fisher 분포에서 새로 뽑지 않고, **관측 절리선의 면내 방향 분포에서 재표집**. (Fisher 표집 절차 식 6.7·6.8은 DFN 생성과 P32 검증용 순방향 모사에는 그대로 사용) |
| 4. 수직거리 d 표집 → ℓ_true 결정 | **삭제** | 참 현길이는 각 로그 구간 I_j에서 **직접 표집**. k_r 의존부가 해석식으로 분리되었기 때문에 반지름·교차거리를 거칠 필요가 없음 |
| 5. 제안영역 표집, A_prop = (W_y+ℓ\|t_y\|)(W_z+ℓ\|t_z\|) | **유지 (역할 변경)** | 중심 균등 표집과 제안영역 면적은 그대로. 다만 A_prop은 표본 가중치 a_s로 커널 분자에 들어가고, **분모는 Σa_s가 아니라 표본 수 \|S_j\|** (식 6.38) — 커널은 조건부확률이 아니라 "단위 중심밀도당 기대 관측빈도"이며, 확률 정규화는 마지막에 전체 셀 합으로 한 번만 수행 (식 6.39) |
| 6. contour 내부 ℓ_viz 측정·절단등급 c 결정 | **유지** | 동일 (막장면 = 평면, 관측창 = 터널 단면 다각형) |
| 7. 가중 분할표 (가중치 합산 예시) | **유지 (의미 변경)** | 가중 집계 방식 그대로 커널 K_jic 계산에 해당. 최종 모형 확률은 w_j(k_r)와 결합한 뒤 정규화 |

## 슬라이드의 두 질문에 대한 답 (재확인)

- **"사후예측분포?"** — 추정된 k̂_r로 모형 (ℓ_vis, c) 분포를 재구성해 관측 분포와
  대조하는 적합도 점검입니다. 절단등급 구성비(Type 0/1/2) 대조를 함께 봅니다.
- **"절리군별 요약값?"** — 절리군별 k̂_r, 지지구간(ΔlogL≤2), bootstrap 신뢰구간,
  적합 표본 수(ℓ_min,fit 이상), 채택 등급을 담은 요약표입니다(최종보고서 표 6-5).

## 참고 — 통화에서 언급된 "표본 5만 개"

종전 순방향 MC 우도에서 **k_r 격자점 하나를 평가할 때마다 가상 절리선 50,000개**를
표집하던 설정입니다(코드 인자 `--mc-samples-per-grid`, 기본값 50,000). 격자 81점을
전부 평가하면 절리군당 수백만 표본이 필요했고, 격자점마다 표집 잡음이 새로 생겨 우도
곡선에 요철이 생기는 원인이기도 했습니다. 최종본(하이브리드)에서는 이 반복 표집이
없어졌고 — k_r 의존부는 해석식, 창·절단 커널은 절리군당 1회(64구간 × 3,000 =
192,000표본) — 5만 표본 설정은 **사후예측 진단의 순방향 모사에만** 남아 있습니다.

## 예상 질문 — "왜 k_r에는 하한 0.5 m를 적용하면서 P32의 P21은 하한 없이 집계하나?"

두 추정량이 짧은 절리선에 반응하는 방식이 다르기 때문입니다.

**k_r은 길이 분포의 "모양"을 개수 기준으로 적합합니다.** 0.5 m 미만 절리선은 개수로는
많고(벤치마크 전처리 기준 623개 중 88개, 약 14%) 측정오차·노이즈 오염이 가장 심한
구간이어서, 포함하면 분포 하한부가 왜곡되어 k_r에 1차적인 편향을 만듭니다. 대신
하한을 그냥 자르는 것이 아니라 **우도 모형(창·절단 커널) 안에 같은 하한을 넣어
절단을 명시적으로 모형화**하므로(식 6.38·6.40), 하한 적용이 편향을 만들지 않고
정보 손실만 감수합니다.

**P32의 P21은 길이의 "총합"입니다.** 짧은 절리선은 개수는 많아도 길이 기여가 작아,
0.5 m 하한을 적용해도 P21은 2–5%밖에 줄지 않습니다(길이가중이라 2차적 영향).
따라서 하한 유무 자체보다 **분자(P21)와 분모(C)의 전제를 일치시키는 것**이
본질입니다. 해석식 C = E[sinφ]는 하한 없는 조건에서 유도되므로 P21도 하한 없이
집계하고, 반대로 양쪽 모두에 하한을 적용한 쌍(P21^ret / C_ℓmin)으로 계산해도
분자·분모가 같은 비율로 줄어 P32 차이는 약 2% 이내임을 확인했습니다(제3절 3.4,
η_det = 0.95–0.99). 즉 어느 쌍을 써도 되며, 표집 변동이 없는 닫힌형 쌍을 기본으로
택한 것입니다.

**실제 현장에서는** 검출 하한 미만의 절리선이 애초에 기록되지 않으므로, 현장의
"전량 집계"는 사실상 ℓ_min,det 이상의 집계입니다. 이 경우가 바로 제3절 3.4의 검증
경로가 다루는 상황입니다 — 관측과 동일한 검출 하한을 적용한 순방향 모사로
η_det = C_ℓmin/E[sinφ]를 산정해 1에서 얼마나 벗어나는지 확인하고, 본 벤치마크처럼
0.95–0.99 수준이면 해석식을 그대로 쓰며, 관측창이 좁거나 검출 하한이 큰 현장에서
η_det가 1에서 크게 벗어나면 C_ℓmin = E[sinφ]·η_det로 전환합니다. 요컨대 현장의
검출 한계는 무시하는 것이 아니라, 별도의 검증 항으로 정량화해 필요할 때만 보정에
반영하는 구조입니다.

## 참고 — 절리선 매칭 "정합 점수"의 삭제·교체

종전 보고서는 여러 막장면의 절리선을 같은 균열로 연결할 때 개별 지표 오차의
가중합으로 정의한 **정합 점수 S = Σ wᵢEᵢ (구판 식 6.15)** 로 후보를 평가했습니다.
최종보고서에서는 이 가중합 점수를 **삭제**하고, 다음의 **하드 게이트 + 증분 병합 +
군집 수용검사** 구조로 교체했습니다(제1절 3항, 제4절 1항).

1. **쌍별 하드 게이트 G_ij (식 6.17)** — ① 절리군 일치, ② 법선 축각 ≤ 15°(식 6.18),
   ③ 상호 공면거리 ≤ 0.15 m, ④ 중심거리 ≤ 2.0 m 의 네 조건을 **모두** 만족해야
   연결 후보가 됩니다. 가중합으로 결합하지 않으므로, 한 지표의 큰 불일치가 다른
   지표의 작은 오차로 상쇄되어 통과하는 일이 없습니다.
2. **증분 병합** — 후보 간선을 공면거리가 작은 순서로 처리하고, 새 절리선을 병합할
   때마다 군집 전체와의 정합성을 다시 평가합니다(쌍별 조건만 만족하는 연쇄 연결 방지).
3. **군집 수용검사** — 병합 후 전체 끝점의 평면 적합 RMS 잔차 ≤ 0.08 m
   (식 6.19–6.22)와 동일 막장면 단일 현 조건(분할 인식된 절리선은 공선 이탈
   0.25 m 이하일 때만 한 절리선으로 인정)을 모두 통과해야 병합이 확정됩니다.

가중 노름 형태의 정합 점수(closeness-of-fit, 식 6.16)는 SKB DFN-R 방법론의 문헌
소개(제1절 2.2.3)에만 남아 있으며, 본 연구의 방법으로는 사용되지 않습니다
(차별점 비교는 표 6-1).

## 참고 — P32

P32 환산계수도 최종보고서에서 **해석식 C = E[sinφ]** (식 6.49, 방향분포만의 닫힌형,
k_r와 무관)로 확정되었습니다. 관측 P21은 하한 없이 전량 집계하며(제3절 3.3), 유한
관측창·최소 길이의 영향은 순방향 모사 검증(η_det = 0.95–0.99, 식 6.52)으로만
다룹니다. 슬라이드 범위(k_r) 밖이지만, 같은 자료를 인용하실 때 함께 반영해 주시면
됩니다.
