D. 결정 필요 사항

D-1. 제7절 민감도 분석의 처리 — 가장 중요한 결정. 현 수치는 v0 추정기 기반이며, 추가로 민감도 스크립트가 호출하는 루트 dfn_analysis/estimate_kr.py의 lmin 선택(best_row)이 참값을 사용하는 오라클 구버전임이 확인되었다(blind 수정은 handoff/handoffv1에만 반영, 루트에는 hybrid 모드 자체가 없음). 따라서 제7절의 k_r 안정성 수치(CV 1.3~4.5%, 편향 −1~−5%)에는 오라클 이득이 섞여 있다.

  • (a) v1 재실행: 시드 민감도(30회)는 현실적(수십 분~1시간). 굴착 간격(400회)·굴착 각도(1,920회)는 장시간 배경 실행 필요. 선행 조건: 루트 dfn_analysis에 v1 미러링 (hybrid 모드 + blind best_row + analytic P32 기본값 이식) — D-2.
  • (b) 주석 처리: 제7절 서두에 "본 절의 민감도는 v0 추정기 기준이며, v1(하이브리드· 고정 lmin)에서는 lmin 선택 요동이 제거되어 k_r 안정성이 이보다 나쁘지 않다"는 취지의 주석을 달고 수치는 유지. (시드 지배 결론·P32 과소경향 등 정성 결론은 v1에서도 유효할 가능성이 높음)
  • 권고: 최소한 시드 민감도(표 6-7)만 v1로 재실행하고, 간격·각도(표 6-8·6-9)는 (b) 주석 처리.

D-2. 루트 dfn_analysis v1 미러링 — D-1(a) 선택 시 필수, 아니어도 권장. handoffv1의 estimate_kr(blind best_row·hybrid 기본·lmin 0.5)· estimate_radius_powerlaw_window_mc(hybrid 커널)·estimate_p32_mc_calibrated(analytic 기본)를 루트 dfn_analysis/로 이식. 현재 루트/배포본 동작 불일치 상태.

D-3. 복원 단계 v1 재실행 — 표 6-3 개수(52/339/55)·그림 6-12를 외부 방향 기준 trace로 갱신할지. 외부 방향에서 유효 법선이 100%가 되므로 연결 게이트(법선 축각) 통과 구성이 달라져 계층별 개수가 이동할 수 있음.
