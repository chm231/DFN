## B. 발견된 표기 오류 (수정 여부와 무관하게 정정 필요)

1. **p.37 표 6-5 Set 2 역산 k_r "2.05" → 3.05.** v0 출력 원본(`pipeline_test_laxemar/comparison_vs_laxemar.csv`)은 3.05이고 본문 p.39도 "3.04에 대해 3.05"로 서술 — 표만 오타. (표를 v1로 교체하면 해소; v1 값은 3.25)
2. **그림 6-10 번호 중복**: p.22(3점법)과 p.27(우도 개념도)이 같은 번호. p.22 그림이 삭제되므로 p.27을 6-10으로 확정하고 이후 번호 재정렬. p.27 캡션 "3길이–절단등급" → "길이–절단등급" 오탈 정정
3. p.36 본문 "(표 6-3)" → 실제 표 번호는 **6-4** (안정성 해석 입력 형식)
4. p.37 본문 "역산 결과는 표 6-4와 같다" → **표 6-5**
5. p.31 "최종 P32는 식 6.47로 계산한다" → **식 6.49** (6.47은 유효 하한 정의)
6. p.32 "정합 점수는 식 6.14와 같이 정의한다" → **식 6.15** (6.14는 DFN-R의 M) — 보완 5로 대체 시 자연 해소
7. p.28 "프로파일 우도 기반 신뢰구간 기반 신뢰구간으로 사용한다" → 중복 구절 정리
8. p.31 절 번호 "5. Kaplan–Meier 진단" → **4.** (제3절 내 4번째 항목)
9. 경미한 오탈: p.13 "즉, 즉," / p.14 "못한지만"→"못하지만" / p.7 "다.다만" 띄어쓰기
10. **p.35 그림 6-12 캡션 좌/우 검토**: 캡션은 "set 4(좌), 5(우)"인데 패널 내용은 왼쪽이
    주황(shrinkage — k_r 보유 절리군에서만 나옴), 오른쪽이 흰색(lower_bound — Set 4는
    k_r 미보유라 전부 하한값)으로 보임 → 좌/우가 뒤바뀐 것으로 판단됨. v1 교체 그림
    기준으로는 set 4 = 흰색 위주, set 5 = 주황+초록이므로 캡션과 패널을 맞춰 배치할 것

## D. 결정 사항 처리 현황

**D-1. 제7절 민감도 분석 — ✅ v1 전면 재실행 완료 (2026-08-03).**
배경: v0 수치는 3점법·window_mc·**오라클 lmin**·unit-MC 기반이었고, 민감도 스크립트가
호출하는 루트 `dfn_analysis/estimate_kr.py`의 lmin 선택이 참값을 쓰는 구버전이었음이
확인되었다. D-2 미러링 후 세 축 모두 v1(외부 3D 방향·hybrid kr·해석식 P32)로
재실행하였다: 시드 30개(θ=0° 부분집합), 굴착 간격 5×20=100 run, 굴착 각도
16×30=480 run (총 1,920 분석, v0와 동일 규모·동일 시드 1–30·동일 그림 포맷).
새 그림·표·절별 재작성 지침은 **§F**. 원자료: `docs/sensitivity_tunnel_angle_v1_results.csv`,
`docs/sensitivity_face_interval_v1_results.csv`.

**D-2. 루트 dfn_analysis v1 미러링 — ✅ 완료 (커밋 `84cc6c3`).**
handoffv1의 estimate_kr(blind best_row·hybrid 기본·lmin 0.5)·
estimate_radius_powerlaw_window_mc(hybrid 커널)·estimate_p32_mc_calibrated(analytic
기본)를 루트 `dfn_analysis/`로 이식. 스모크 테스트로 배포본과 동일 결과 확인
(kr 2.70/3.25/3.50/3.90). 민감도 스크립트 2종도 analytic P32로 전환.

**D-3. 복원 단계 v1 재실행 — ✅ 완료 (2026-08-03).** 외부 방향 trace + v1 kr 요약으로

### F-5. 본문 서술 변경 포인트 (절별)

**제7절 1 (시드).**
- k_r 문단: "편향 약 −1~−5%로 거의 무편향" → "**편향 ±3% 이내(+2.8/+0.4/+1.6/−0.7%)로
  거의 무편향이며, CV(7.2~12.1%)도 세 지표 중 가장 작다**"로 교체. 이 안정성이 **참값
  미사용 고정 ℓ_min(0.5 m)에서 얻어진 것**임을 한 문장 명기할 것(종전 수치는 오라클
  선택 포함).
- κ 문단: "Set 1·2·3 소폭 과소, Set 5 소폭 과대" 서술 폐기 → "Set 1·3 과대(+7.8/+14.3%),
  표본이 가장 적은 Set 2 과소(−13.9%), Set 5 거의 무편향(+1.8%)"으로 교체.
- P32 문단: 과소 경향(−4~−16%) 서술 유지, 수치만 갱신. "표본 수가 적은 Set 1과 Set 2에서
  크게" → "Set 1·2에서 크게(−12.7/−15.9%)"로 유지 가능.

**제7절 2 (간격).**
- 표 교체 후 본문 "CV 약 1.6~5.2%" → "**약 1.1~4.3%**", "시드 CV 10~22%보다 뚜렷하게
  작다" → "**시드 CV 7~20%보다 뚜렷하게 작다**". 결론(간격 영향 제한적, 시드 지배) 유지.

**제7절 3 (각도).**
- "각도 영향을 가장 많이 받는 값은 κ" **유지**하되 수치 갱신: "약 3.5~8.0%" →
  "**약 1.9~11.4%**". 원인 서술 보강: 외부 3D 방향을 쓰면서 교차 표본편향(막장면에
  수직인 절리가 과대표집되는 효과)의 각도 의존이 κ 추정에 그대로 드러난다
  (v0의 3점법은 법선 잡음이 이 구조를 가리고 있었음).
- k_r 문단: "CV 1.3~3.3%로 가장 안정" → "**CV 0.6~2.4%로 가장 안정**", "편향 ±3% 이내"
  → "전 각도 pooled 편향 −4.4~+6.0%" 수준으로 갱신. 하이브리드 우도가 각도 변화에
  강건함을 보여준다는 취지 유지.
- P32 문단: "대체로 −5~−17% 과소" → "**−0.1~−18.6% 과소(Set 1 최대)**". unit-MC 언급
  삭제(해석식 보정으로 교체되었으므로 "해석식 보정 하에서도 과소 경향은 관측 P21의
  표본 변동과 방향 추정 편향(자기완결 구성)에서 기인" 취지로).

**제7절 4 (종합).**
- "시드 변화 CV 약 10~22%" → "**약 7~20%**". "간격·각도 변동 대부분 8% 이하" →
  "**간격 1.1~4.3%, 각도는 k_r·P32가 8% 이하이며 κ만 최대 11.4%**".
- "지표별로는 k_r이 가장 안정적" **유지** — 단, "**참값을 일절 쓰지 않는 v1 추정기(고정
  ℓ_min·blind 선택)에서 확인된 결과**"임을 명기(방법론 신뢰성의 핵심 근거가 됨).
- 나머지(시드 지배, Set 5 최안정·Set 2 최불안정, 다중 실현 평균 보고 권고) 유지.
