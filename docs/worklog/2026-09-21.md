# 2026-09-21 다면 관통을 반지름 정보로 쓸 수 있는가 — 검토 결과 불가(근거: association 민감도)

브랜치 `feat/enkf-feasibility` / 작업 위치 `handoffv3/scripts/multiface/`

## 배경
9-17 §(8) 에서 "면 간 중복이 kr 을 편향시킨다"고 했으나 9-21 에 정정했다
(합성 시험: 다면 풀링은 현길이 주변분포를 바꾸지 않는다).
그러면 전방 모형 다면 확장의 가치는 편향 제거가 아니라 **다면 관통을 반지름 정보로
쓰는 것**이다. 한 균열이 Δx 떨어진 두 면을 다 자르려면 r >= Δx/(2 sinφ) 여야 하므로
기하학적으로 엄밀한 하한이 나온다. 현행 우도는 이 정보를 전혀 쓰지 않는다.
그 정보가 실제로 쓸 만한지 진단했다.

## 진단 1 — 관통 면 수 분포 P(k)
`scripts/multiface/kspan_diagnostic.py`.
kr 격자마다 원판을 3D 생성(반지름 powerlaw, 법선은 관측 트레이스 법선 재표집,
중심 균등)하고 7개 막장면에서 현 계산 → 관측창 클리핑 → 검출하한 0.5 m 적용 →
관통 면 수 k 의 모형 분포와 관측(복원 association) 분포를 다항우도로 대조.

| set | 관측 P(k>=2) | 모형 P(k>=2) @현행 kr | k-최적 kr | 현행 kr |
|---|---|---|---|---|
| 1 | 0.096 | 0.011 | 2.6 | 3.90 |
| 2 | 0.160 | 0.008~0.014 | 2.8 | 3.85 |
| 3 | 0.070 | 0.023 | 3.4 | 3.70 |

모형이 다면 관통을 7~20배 과소예측. 다만 kr 을 2.6 까지 낮춰도 관측에 못 미쳐
(모형 0.067 vs 관측 0.096) kr 만의 문제가 아님을 시사.

## 진단 2 — 반지름 하한 분포
각 복원 원판에 대해 r_low = span/(2 sinφ) (다면 관통 시에만 정의, 단일면은 0).
**기하학적으로 엄밀한 하한**이므로 실제 반지름은 이보다 크다.

| | r>=1.0m | r>=1.5m | r>=2.0m | r>=3.0m |
|---|---|---|---|---|
| 관측(하한) | 10.6 % | **7.1 %** | **4.2 %** | **1.9 %** |
| 모형 kr=3.9 (현행) | 18.2 % | 4.7 % | 2.0 % | 0.5 % |
| 모형 kr=3.4 | 23.6 % | 10.7 % | 5.5 % | 1.9 % |
| 모형 kr=3.0 | 28.7 % | 13.1 % | 7.1 % | 4.0 % |

kr=3.9 는 r>=1.5/2.0/3.0 에서 **관측 하한보다도 낮다** → 데이터가 확실히 가진 것보다
큰 균열을 적게 예측. 이 대조만 보면 kr <= 3.4 가 요구된다.
(모형이 관측 법선 풀을 쓰므로 막장면 평행 쪽으로 이미 편향돼 다면 관통을 과대
예측하는 방향이다. 즉 불일치는 보수적으로 잡힌 값이다.)

## 그러나 — association 민감도에서 결론이 무너진다
같은 절리선 자료에 association 설정만 바꿔 관측 하한을 다시 계산:

| association 설정 | 원판수 | 다면 | r>=1.0 | r>=1.5 | r>=2.0 | r>=3.0 |
|---|---|---|---|---|---|---|
| **기본**(adaptive, 15°, 0.15 m, cap 8) | 3,061 | 345 | 10.6 % | **7.1 %** | 4.2 % | 1.9 % |
| 각도 엄격 10° | 3,501 | 313 | 8.3 % | 5.2 % | 2.8 % | 1.1 % |
| 공면 엄격 0.08 m | 3,792 | 183 | 4.6 % | **3.1 %** | 1.5 % | 0.4 % |
| 근접 상한 cap 4.5 | 3,150 | 287 | 8.5 % | 5.1 % | 2.7 % | 1.3 % |
| 비적응 max_sep 2.0 | 3,663 | **5** | 0.1 % | **0.0 %** | 0.0 % | 0.0 % |
| 모두 엄격(10°, 0.08 m, cap 4.5) | 4,103 | 120 | 2.8 % | **1.6 %** | 0.5 % | 0.2 % |

r>=1.5 m 비율이 **7.1 % ~ 0.0 %** 로 요동한다. 모형 kr=3.9 의 4.7 % 는 이 범위 한가운데다.
**즉 다면 관통 신호는 DFN 이 아니라 association 설정이 지배한다.**

## 결론
1. **kr 이 편향됐다고 말할 수 없다.** 진단 1·2 가 가리킨 kr<=3.4 는 느슨한 association
   에서만 성립하고, 엄격한 설정에서는 현행 kr=3.9 가 오히려 관측을 과대예측한다.
2. **다면 관통을 반지름 정보로 쓰는 아이디어는 현 상태로 성립하지 않는다.**
   전제(다면 관통이 신뢰성 있게 식별된다)가 깨졌다.
3. 따라서 **전방 모형 다면 확장의 우선순위를 내린다.** 선결 과제는 association 검증이다.

## 파급 — association 불확실성은 여기에만 걸리는 문제가 아니다
복원 원판은 조건부 DFN 의 visible disc, 쐐기 선별, 블록 확률장에 모두 들어간다.
설정에 따라 원판 수가 3,061~4,103 (34 % 차이), 다면 관통이 345~5 로 변한다.
현행 채택값(적응 게이트, 0.15 m)은 260910 자료의 "다면 매칭 적응 게이트 171→280→308"
경로로 정해진 것인데, 그 선택이 다면 관통 판정을 크게 좌우한다는 점이 확인됐다.

## 다음에 할 것
association 정확도를 **정답이 있는 자료**로 재보정해야 한다. 실측 DFM 자료에는
원판 정답 라벨이 없다(`fracture_id` 4,630개가 전부 고유한 일련번호).
합성 벤치마크(oracle association, `component_id`)로 설정별 과병합/과분할률을 재고,
그 위에서 다면 관통 신호의 신뢰구간을 정하는 것이 순서다.

## 미확인
- 합성 벤치마크 자료가 현재 저장소에서 바로 쓸 수 있는 상태인지 확인하지 않았다.
- 진단 1 의 모형은 중심을 x/y/z 균등 배치한다. 실제 균열 공간분포의 비정상성은 고려 안 함.
- rmax 는 25 m 로 잘랐다(파이프라인 생성값 250 m). kr≈3~4 에서 P(r>25)≈1e-7 이라 무시 가능.
