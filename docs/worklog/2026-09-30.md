## 절리선 길이–각도 의존성 검정 재확인 (다른 세션 결과에 대한 교차검정)

배경: 다른 세션이 "절리선 길이가 균열면–막장면 각도에 강하게 의존한다 → 끝점이 (b) 탐지 패치
경계다"라고 판단하고, 그에 따라 (i) 길이 대신 간격 기반 P32, (ii) kr은 lmin ≥ 1 m + 불확실성 확대,
(iii) D025 기록을 제안했다. 세 가지를 직접 검정했다.
스크립트: `handoffv2/scripts/analysis_260930/` (angle_length.py, angle_noise.py, normal_consistency.py)

### (1) 제안된 "반현/반지름 ≈ 0.79" 검정은 순환이다 — 결론 불가

원자료 3D 끝점(`3D_disk_data.csv` TraceP1/P2, 비투영)으로 계산:
**(L/2)/R = 중앙 1.008, 5~95 % 0.879~1.359.** 무작위 현 모형 기대값 0.785(0~1 넓게 분포)와 명확히 다르고
1.0에 집중한다. 원판 중심–절리선 중점 거리는 중앙 0.0215 m (반길이의 0.139).

→ DFM 원판은 절리선에서 파생된 값이고 교선은 항상 거의 지름이다. 그런데 이것은 **`Radius` 열이
파생값이라는 뜻일 뿐, 끝점이 (a)인지 (b)인지는 말해주지 않는다.** 원판이 절리선에 맞춰 그려졌으니
절리선을 기준으로 원판을 재는 검정은 정의상 1이 나온다. 이 검정으로 (b)를 지지할 수 없다.
참고로 변환기는 이미 `radius_m = NaN`으로 두고 DFM `Radius`를 쓰지 않는다 — 영향 없음.

### (2) 각도–길이 의존성은 실재하나 (b)의 증거로는 불충분

이면각 α = acos|n·f| (0° = 균열이 막장면과 평행, 90° = 수직). 비검열 5,957개만 사용.
순수 현 모형에서 길이 분포는 α와 무관해야 한다 — sinφ는 교차 *개수*에만 들어가고
반현 = r√(1−u²), u~U[−1,1], E = π/4 ≈ 0.785 는 φ에 무관하다.

| 통제 | set 1 | set 2 | set 3 | set 4 |
|---|---|---|---|---|
| set 내부 (전 면) | ρ=−0.258 | −0.347 | −0.231 | −0.409 |
| + 고해상 7면 | −0.211 | −0.261 | −0.206 | −0.374 |
| + L ≥ 0.5 m | **−0.097 (p=0.078, 유의하지 않음)** | −0.233 | −0.132 | −0.231 |

상관은 set 내부에서도 살아남지만 **검출하한 0.5 m 위에서는 set 1에서 사라지고 set 3에서 약해진다.**
즉 의존성의 대부분이 우리가 이미 제외하는 0.5 m 미만 구간에 있다.

교란 확인 — 짧은 절리선의 법선 품질이 나쁘다:
- set 평균축과의 축간각 편차 90백분위: set 1 0~0.2 m에서 **40.9°** → 1.5 m 이상에서 **25.8°**
  (set 3은 45.8° → 23.8°). 길이 vs 편차 ρ = −0.16 ~ −0.32 (전부 p < 1e-13).
- α 중앙값이 모든 set에서 짧을수록 **45°(무정보 균등분포의 중앙)로 이동**한다.
  set 1 50.9° → 38.0°, set 2 46.6° → 30.8°, set 3 41.3° → 32.3°, set 4 24.9° → 12.7°.
  법선이 trace 축 주위로 자유로워지면 |n·f|가 무작위가 되어 α~U[0,90]이 된다 — 이 패턴과 일치.

→ 패치 경계 기제와 법선 잡음 기제가 **같은 부호를 예측**하고, 짧은 절리선에서 법선 품질이
실제로 나쁘다. 현 자료로는 둘을 분리할 수 없다. (b)를 확정한 것으로 볼 수 없다.

### (3) 더 강한 발견 — 패치 법선이 자기 절리선에 수직이 아니다

절리선은 균열면 위의 선이므로 반드시 **n · t = 0**. 원자료 3D 끝점으로 검정:

| 백분위 | 50 | 75 | 90 | 95 | 99 | 최대 |
|---|---|---|---|---|---|---|
| 수직성 위반 | **8.26°** | 16.71° | 27.52° | 35.48° | 54.78° | 80.63° |

5° 초과 64.9 %, 10° 초과 43.4 %, 20° 초과 19.2 %.
길이대별로 거의 평평하다(7.1° / 9.6° / 9.0° / 9.6° / 9.1° / 5.8°) — **짧은 절리선 적합 문제가 아니라
전 구간에 걸친 계통 불일치**다. `Normal*`과 `TraceP1/P2`가 서로 정합하지 않는다.

→ DFM 팀에 물을 것이 "끝점 정의"보다 이쪽이 더 구체적이고 검증 가능하다.
→ 변환기·복원 단계가 패치 법선을 균열 방향으로 그대로 쓰므로 이 8°는 하류로 전파된다.
