제6장 검증표 — v2 파이프라인 재생성 결과 (2026-08-07 결정 반영)

v2에서 바뀐 것 두 가지 (「0807 샌드박스」)

  1. 관측 기준: 제6장 범위가 "제5장 전달 2차원 절리선"부터로 축소되면서, 검증용 합성 절리선도 평면 막장면 × 터널 단면 다각형으로 생성한다 (export_flat_face_traces). 관측면적 $A_{obs}$ = 다각형 면적 × 막장면 수로 모델 창 기준과 정확히 일치한다.
  2. P32 보정계수: 순수 해석식 $C=E[\sin\phi]$ 대신 $C_{\ell_{\min}}=E[\sin\phi]\cdot\eta_{det}$ 를 순방향 모사에서 직접 산정한다 (--calibration-factor-mode forward_mc_lmin --lmin 0.5). 관측자료와 가상자료에 동일한 최소 길이 기준을 적용한다.

입력 DFN 참값은 v0/v1과 동일 파일로 고정했으므로, 아래 차이는 전부 관측 기준과 보정 정의의 변경에 기인한다. 대상: Laxemar, 막장면 4매(x = 0/1/2/3 m), 절리군 1·2·3·5.

3. $P_{32}$ 신뢰구간 — 보고서에는 점추정만 제시한다 (결정, 2026-08-07)

3.1 v2에서 구간 산출 자체는 가능해졌다

v1의 해석식 보정은 결정론적 구적이라 $C$에 표집 불확실성이 없어 신뢰구간이 점추정값과 같아지는 퇴화 상태였다(검증표 v1 §3.1의 미해결 항목). v2는 $B$회 반복 모사의 산포로 $C$의 분산을 얻으므로 구간이 정상적으로 계산된다.

절리군 $\widehat{P_{32}}$ 산출된 95% CI 폭
1 0.968 [0.910, 0.972] 0.062
2 0.791 [0.798, 0.801] 0.003
3 0.987 [0.988, 0.992] 0.004
5 1.015 [1.016, 1.016] 0.000

3.2 그러나 이 구간은 보고서에 싣지 않는다

결정: 보고서 표 6-5에는 $\widehat{P_{32}}$ 점추정만 싣고 신뢰구간 열은 두지 않는다.

이유는 위 구간이 $P_{32}$의 참 불확실성이 아니기 때문이다. 현재 구간은 $k_r$ 불확실성 전파와 MC 반복 산포만 담고 있고, 관측 $P_{21}$ 자체의 표본 변동 (막장면 수·절리선 수의 유한성)은 포함하지 않는다. 그 결과 Set 2·3·5처럼 구간이 매우 좁아 점추정값을 근소하게 벗어나는 모순이 생긴다(Set 2: 추정 0.791, 구간 [0.798, 0.801]). 불완전한 구간을 신뢰구간으로 제시하면 실제보다 정밀한 추정이라는 오해를 준다.

$P_{32}$의 실질 불확실성은 제7절 민감도 분석의 시드 산포(CV 11.2~24.1%)가 훨씬 현실적인 지표이므로, 불확실성을 언급해야 할 때는 그쪽을 인용한다.

차기 개선 항목: 관측 $P_{21}$의 표본 변동(예: 막장면 단위 블록 부트스트랩)을 포함한 구간을 구성하면 그때 표에 실을 수 있다.

⚠ $k_r$의 신뢰구간은 이 결정과 무관하다. $k_r$는 프로파일 우도($\Delta\log L\le2$)와 부트스트랩으로 구한 정상적인 구간이므로 종전대로 제시한다.

4. 최소 길이 기준의 자기정합성 확인

$\ell_{\min}$을 0 → 0.5 m로 바꾸면 분자($P_{21}^{ret}$)와 분모($C_{\ell_{\min}}$)가 함께 줄어들어 $\widehat{P_{32}}$는 거의 변하지 않는다. "관측자료와 가상자료에 동일한 기준을 적용한다"는 원칙이 실제로 작동함을 보여주는 직접 검증이다.

절리군 $\ell_{\min}=0$: $P_{21}^{ret}$ / $C$ / $\widehat{P_{32}}$ $\ell_{\min}=0.5$: $P_{21}^{ret}$ / $C$ / $\widehat{P_{32}}$ $P_{32}$ 변화
1 0.7886 / 0.8164 / 0.966 0.7660 / 0.7911 / 0.968 +0.2%
2 0.2518 / 0.3151 / 0.799 0.2462 / 0.3111 / 0.791 −1.0%
3 0.7734 / 0.7849 / 0.985 0.7606 / 0.7707 / 0.987 +0.1%
5 0.6016 / 0.5939 / 1.013 0.5738 / 0.5656 / 1.015 +0.2%

최소 길이 기준을 0.5 m로 올리면 관측 $P_{21}$이 2~5% 줄지만 보정계수도 같은 비율로 줄어, 최종 $P_{32}$ 변화는 −1.0~+0.2%에 그친다. 종전처럼 관측에만 임계값을 적용하고 보정계수에는 적용하지 않으면 이 상쇄가 일어나지 않아 $P_{32}$가 임계값에 직접 끌려간다.

6. 재현 명령

# 1) 검증용 합성 절리선 (평면 막장면 × 터널 단면 다각형)
python -m dfn_analysis.export_flat_face_traces \
  --dfn-h5 storage/output/pipeline_test_laxemar/dfn_export_for_python.h5 \
  --face-x 0 1 2 3 --outdir storage/output/pipeline_v2_laxemar/trace_dataset

# 2) kr (hybrid, lmin 0.5 고정, 참값 미사용 선택)
python -m dfn_analysis.estimate_kr \
  --trace-h5 storage/output/pipeline_v2_laxemar/trace_dataset/trace_dataset_3d.h5 \
  --site laxemar --target-set 1 2 3 5 --kr-true-map 1:2.85 2:3.04 3:3.01 5:3.60 \
  --run-bootstrap --n-bootstrap 100 \
  --outdir storage/output/pipeline_v2_laxemar/kr

# 3) P32 (C_lmin = E[sinφ]·η_det, 관측·가상 동일 lmin)
python -m dfn_analysis.estimate_p32_mc_calibrated \
  --trace-h5 storage/output/pipeline_v2_laxemar/trace_dataset/trace_dataset_3d.h5 \
  --dfn-h5 storage/output/pipeline_test_laxemar/dfn_export_for_python.h5 \
  --rough-mesh-h5 storage/output/flat_face_mesh/flat_face_collection.h5 \
  --site laxemar --target-set 1 2 3 5 \
  --kr-summary-csv storage/output/pipeline_v2_laxemar/kr/kr_summary_by_set.csv \
  --bootstrap-csv storage/output/benchmark1_parsimonious/inputs/final_kr_bootstrap_summary_effective_rmin.csv \
  --calibration-factor-mode forward_mc_lmin --lmin 0.5 \
  --outcsv storage/output/pipeline_v2_laxemar/p32/p32_summary.csv

# 4) 복원 + 참값 대조표
python -m dfn_analysis.reconstruct_discs_from_traces \
  --trace-h5 storage/output/pipeline_v2_laxemar/trace_dataset/trace_dataset_3d.h5 \
  --kr-summary-csv storage/output/pipeline_v2_laxemar/kr/kr_summary_by_set.csv \
  --out-csv storage/output/pipeline_v2_laxemar/reconstruct/reconstructed_discs.csv
python scripts/compare_pipeline_to_laxemar.py --base storage/output/pipeline_v2_laxemar
