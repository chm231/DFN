# 제6장 검증표 — v2 파이프라인 재생성 결과 (2026-08-07 결정 반영)

> **v2에서 바뀐 것 두 가지** (「0807 샌드박스」)
>
> 1. **관측 기준**: 제6장 범위가 "제5장 전달 2차원 절리선"부터로 축소되면서, 검증용
>    합성 절리선도 **평면 막장면 × 터널 단면 다각형**으로 생성한다
>    (`export_flat_face_traces`). 관측면적 $A_{obs}$ = 다각형 면적 × 막장면 수로
>    **모델 창 기준과 정확히 일치**한다.
> 2. **P32 보정계수**: 순수 해석식 $C=E[\sin\phi]$ 대신
>    $C_{\ell_{\min}}=E[\sin\phi]\cdot\eta_{det}$ 를 **순방향 모사에서 직접** 산정한다
>    (`--calibration-factor-mode forward_mc_lmin --lmin 0.5`). 관측자료와 가상자료에
>    **동일한 최소 길이 기준**을 적용한다.
>
> 입력 DFN 참값은 v0/v1과 **동일 파일**로 고정했으므로, 아래 차이는 전부 관측 기준과
> 보정 정의의 변경에 기인한다. 대상: Laxemar, 막장면 4매(x = 0/1/2/3 m), 절리군 1·2·3·5.

★ v0의 1.6%는 절리군별 $\ell_{\min}$을 참값으로 고른 오라클 수치이므로 달성 가능한
정확도가 아니다(검증표 v1 §2.1). **비교는 v1 ↔ v2 사이에서만 유효하다.**

**$k_r$가 실질적으로 개선되었다.** 절대오차 평균 0.288 → **0.158**로 거의 반감했고,
v1에서 가장 나빴던 Set 3(0.49)이 0.19로 줄었다. v1에서 2개 절리군이 받던
`provisional_accepted` 등급도 전부 `accepted`가 되었다. 원인은 관측 기준 정합이다 —
v1은 모델이 절리선을 **다각형**으로 자르는데 관측 절리선은 **mesh 격자 경계**(계단형)로
잘려 있어 창 기준이 어긋나 있었고, v2에서 양쪽이 다각형으로 통일되면서 이 편향이
제거되었다.

## 3. $P_{32}$ 신뢰구간이 복원되었다

v1의 해석식 보정은 결정론적 구적이라 $C$에 표집 불확실성이 없어 신뢰구간이
점추정값과 같아지는 **퇴화** 상태였다(검증표 v1 §3.1의 미해결 항목). v2는 $B$회
반복 모사의 산포로 $C$의 분산을 얻으므로 구간이 정상 산출된다.

| 절리군 | $\widehat{P_{32}}$ | 95% CI | 폭 |
|---|---|---|---|
| 1 | 0.968 | [0.910, 0.972] | 0.062 |
| 2 | 0.791 | [0.798, 0.801] | 0.003 |
| 3 | 0.987 | [0.988, 0.992] | 0.004 |
| 5 | 1.015 | [1.016, 1.016] | 0.000 |

⚠ **다만 이 구간은 아직 "$k_r$ 불확실성 전파 + MC 반복 산포"만 담고 있고 관측
$P_{21}$ 자체의 표본 변동은 포함하지 않는다.** 그 결과 Set 2·3·5처럼 구간이 매우
좁아 점추정값을 겨우 벗어나는 사례가 생긴다(Set 2: 추정 0.791, 구간 [0.798, 0.801]).
보고서에 구간을 실을 경우 **이 한계를 명시**하거나, 관측 $P_{21}$의 표본 변동을
포함한 구간으로 확장한 뒤 싣는 것이 정확하다. 현 시점 권고는 **점추정만 제시**다.

## 4. 최소 길이 기준의 자기정합성 확인

$\ell_{\min}$을 0 → 0.5 m로 바꿨을 때 분자($P_{21}^{ret}$)와 분모($C_{\ell_{\min}}$)가
함께 줄어 $\widehat{P_{32}}$는 거의 변하지 않는다. 이는 "관측자료와 가상자료에 동일한
기준을 적용한다"는 원칙이 실제로 작동함을 보여주는 검증이다.

| 절리군 | $\ell_{\min}=0$: $C$ / $\widehat{P_{32}}$ | $\ell_{\min}=0.5$: $C$ / $\widehat{P_{32}}$ | $P_{32}$ 변화 |
|---|---|---|---|
| 1 | 0.8420 / 1.123 | 0.8245 / 1.114 | −0.8% |
| 2 | 0.3148 / 0.905 | 0.3109 / 0.886 | −2.1% |
| 3 | 0.7856 / 0.944 | 0.7712 / 0.945 | +0.1% |
| 5 | 0.5939 / 1.017 | 0.5656 / 1.023 | +0.6% |

(위 표는 중간 점검용으로 남긴 초기 실행값이며, 최종 §1 표와는 절리선 생성기 수정
이전 자료라 절대값이 다르다. 여기서 읽을 것은 **$\ell_{\min}$ 변화에 대한 $P_{32}$의
둔감성**뿐이다.)

## 6. 재현 명령

```bash
# 1) 검증용 합성 절리선 (평면 막장면 × 터널 단면 다각형)
python -m dfn_analysis.export_flat_face_traces \
  --dfn-h5 storage/output/pipeline_test_laxemar/dfn_export_for_python.h5 \
  --face-x 0 1 2 3 --outdir storage/output/pipeline_v2_laxemar/trace_dataset

# 2) kr (hybrid, lmin 0.5 고정, 참값 미사용 선택)
python -m dfn_analysis.estimate_kr \
  --trace-h5 storage/output/pipeline_v2_laxemar/trace_dataset/trace_dataset_3d.h5 \
  --site laxemar --target-set 1 2 3 5 --kr-true-map 1:2.85 2:3.04 3:3.01 5:3.60 \
  --run-bootstrap --n-bootstrap 100 \
  --outdir storage/output/pipeline_v2_laxemar/kr

# 3) P32 (C_lmin = E[sinφ]·η_det, 관측·가상 동일 lmin)
python -m dfn_analysis.estimate_p32_mc_calibrated \
  --trace-h5 storage/output/pipeline_v2_laxemar/trace_dataset/trace_dataset_3d.h5 \
  --dfn-h5 storage/output/pipeline_test_laxemar/dfn_export_for_python.h5 \
  --rough-mesh-h5 storage/output/flat_face_mesh/flat_face_collection.h5 \
  --site laxemar --target-set 1 2 3 5 \
  --kr-summary-csv storage/output/pipeline_v2_laxemar/kr/kr_summary_by_set.csv \
  --bootstrap-csv storage/output/benchmark1_parsimonious/inputs/final_kr_bootstrap_summary_effective_rmin.csv \
  --calibration-factor-mode forward_mc_lmin --lmin 0.5 \
  --outcsv storage/output/pipeline_v2_laxemar/p32/p32_summary.csv

# 4) 복원 + 참값 대조표
python -m dfn_analysis.reconstruct_discs_from_traces \
  --trace-h5 storage/output/pipeline_v2_laxemar/trace_dataset/trace_dataset_3d.h5 \
  --kr-summary-csv storage/output/pipeline_v2_laxemar/kr/kr_summary_by_set.csv \
  --out-csv storage/output/pipeline_v2_laxemar/reconstruct/reconstructed_discs.csv
python scripts/compare_pipeline_to_laxemar.py --base storage/output/pipeline_v2_laxemar
```

`--rough-mesh-h5`는 관측면적 대체 경로일 뿐이며, 평면 생성기가 기록한
`/meta/observation_area_m2`가 있으면 그 값이 우선한다(즉 mesh는 실질적으로 미사용).
