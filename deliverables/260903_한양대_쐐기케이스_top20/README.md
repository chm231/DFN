   ② 방향 입력 규약 차이(아래 참조) 중 하나로 추정됩니다.

## 좌표·방향 규약 (top20_fractures.csv)

- 좌표: x = 굴진 방향, z = 상방(연직 위), 단위 m. 도메인 x 12.688~22.688.
- `nx,ny,nz`: 절리면 단위 법선 벡터 — **이 값을 쓰면 규약 모호성이 없습니다.**
- `dip_deg`: 경사각(수평면 기준). `pole_trend_deg`: 상향 법선의 방위각
  (**atan2(ny,nx), +x축 기준 반시계** — 지리 방위각 아님).
  `dipdir_deg_trendconv` = pole_trend + 180.
- 무한평면 확장 시 center와 법선만 사용하면 됩니다(radius는 참고).
