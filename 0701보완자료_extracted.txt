1. 전체 파이프라인 개요
본 연구의 전체 목적은 터널 굴진 중 막장면에서 관찰되는 2차원 trace 정보를 이용하여, 3차원 암반균열망(DFN, Discrete Fracture Network)의 주요 통계 파라미터를 추정하고, 관측되지 않은 터널 전방 및 주변부의 가상 암반균열망을 생성하는 것임.
전체 파이프라인은 다음 순서로 구성됨.
1. 막장면별 trace 데이터 입력2. trace 전처리- 길이, 중심점, 2차원 방향각 계산- 터널 경계와의 교차 여부 분류- 임계 길이 이하 trace 제거3. 절리군별 trace 분류- 방향성 기반 분류- normal vector, trend/plunge 추정4. 관찰 균열 연결- 인접한 여러 막장면에서 동일 절리군 trace 후보 탐색- 동일 평면성 평가- 최적 trace 조합 선정- 관찰 균열 원판 또는 평면 복원5. trace 길이 분포 보정- window censoring 보정- Kaplan–Meier 또는 MC likelihood 기반 보정6. DFN 파라미터 추정- 절리군별 방향성- 반지름 분포 kr- P327. 가상 암반균열망 생성- 관측 균열 복원 영역- 미관측 영역 조건부 DFN 생성
현재까지 완료된 핵심 부분은 trace 기반 반지름 분포 kr 역산, set-specific effective rmin 보정, window-aware Monte Carlo likelihood, P32 unit-P32 forward-MC calibration, bootstrap 불확실성 평가임.관찰 균열 연결 및 최적 평면 복원 알고리즘은 현재 구현 전 설계 단계이며, 아래와 같은 방식으로 적용 예정임.
2. 관찰 균열 연결 알고리즘
2.1 여러 막장면에 나타난 동일 절리군 trace 연결 알고리즘
2.1.1 기본 개념
N번째 막장면에 있는 trace와, N+1~N+3번째 막장면에 있는 동일 절리군 내 trace들은 동일한 3차원 균열면이 굴진 방향을 따라 반복적으로 노출된 결과일 수 있음.따라서 각 막장면에서 관측된 trace 후보들을 조합하여, 하나의 3차원 균열면으로 설명 가능한지를 평가함.
본 알고리즘의 목적은 다음 두 가지임.
1. 서로 다른 막장면에 나타난 trace들이 동일 균열인지 판정2. 동일 균열로 판단되는 trace 조합으로부터 최적 균열면을 복원
2.1.2 “동일 평면 가능성” 평가 방법
동일한 원판형 또는 평면형 균열이 여러 막장면과 교차하면, 각 막장면에서는 선분 형태의 trace가 관측됨.따라서 여러 trace가 동일 균열에서 유래했다면, 각 trace의 양 끝점 또는 중심점은 하나의 3차원 평면에 가깝게 놓여야 함.
이를 위해 다음 점들을 사용함.
- trace 중심점- trace 양 끝점- 막장면 위치 x- face-local 좌표 y, z
각 trace는 막장면 좌표계에서 다음과 같이 3차원 점으로 변환됨.
P1 = (x_face, y1, z1)P2 = (x_face, y2, z2)Pc = (x_face, yc, zc)
후보 trace 조합에 대해 평면을 피팅하고, 각 trace endpoint 또는 중심점이 해당 평면에서 얼마나 벗어나는지를 계산함.
평면은 다음 식으로 정의함.
n · (p - p0) = 0
여기서,
n  = 평면 normal vectorp0 = 평면 위 기준점p  = trace endpoint 또는 중심점
평면성 오차는 다음과 같이 계산함.
d_i = | n · (p_i - p0) |
후보 조합의 동일 평면성 점수는 다음 항목을 조합하여 산정함.
1. 평면 거리 오차2. trace 방향각 일관성3. 절리군 평균 방향과의 차이4. 막장면 간 위치 연속성5. 복원된 균열 반지름의 물리적 타당성
최종 점수 예시는 다음과 같음.
Score = w1 * plane_error      + w2 * direction_error      + w3 * set_normal_error      + w4 * radius_penalty      + w5 * continuity_penalty
점수가 가장 낮은 조합을 동일 균열 후보로 선정함.
2.1.3 최적 절리선 조합 계산 방법
N번째 막장면의 trace 하나를 기준으로, N+1~N+3번째 막장면에서 동일 절리군에 속하는 trace들을 후보군으로 구성함.
예를 들어 각 막장면에서 후보 trace가 여러 개 있을 경우, 가능한 조합은 다음과 같음.
Candidate combination:  {trace_N, trace_N+1, trace_N+2, trace_N+3}
단, 모든 막장면에서 반드시 trace가 존재해야 하는 것은 아님. 균열이 특정 막장면에서는 터널 단면과 교차하지 않거나, 교차하더라도 임계 길이 이하로 관측되지 않을 수 있기 때문임. 따라서 2개 이상 trace가 연결 가능하면 후보 조합으로 평가함.
조합 탐색 방식은 다음과 같음.
1. 기준 trace 선택2. 동일 절리군 내 인접 막장 trace 후보 추출3. 가능한 trace 조합 생성4. 각 조합에 대해 3D 평면 피팅5. 평면성 오차 및 방향성 오차 계산6. 가장 낮은 score를 갖는 조합 선택7. score가 임계값 이하일 때만 동일 균열로 연결
초기 구현에서는 완전탐색 방식으로 후보 조합을 평가할 수 있음.후보 수가 증가하면 Hungarian matching, graph matching, RANSAC 기반 평면 피팅으로 확장 가능함.
2.1.4 반복 수행 여부 및 수렴 기준
trace 연결은 한 번에 전체를 결정하기보다 반복적으로 수행하는 방식이 적절함.초기에는 가장 신뢰도 높은 연결부터 확정하고, 이후 남은 trace에 대해 반복적으로 연결 후보를 탐색함.
반복 알고리즘은 다음과 같음.
1. 모든 후보 조합 score 계산2. 가장 낮은 score의 조합 선택3. score가 임계값 이하이면 하나의 관찰 균열로 확정4. 해당 trace들을 후보군에서 제거5. 남은 trace로 다시 후보 조합 계산6. 더 이상 score 기준을 만족하는 조합이 없으면 종료
수렴 기준은 다음 중 하나를 사용함.
- 새로 연결되는 trace 조합이 없음- 최소 score가 허용 임계값보다 큼- 반복 횟수가 최대값에 도달- 전체 연결 결과 변화율이 일정 기준 이하
따라서 1, 2번 과정은 반복 수행되는 구조임.
2.2 최적 절리선에 대한 균열 복원 알고리즘
2.2.1 복원 대상 형상
관찰 trace로부터 복원하는 균열은 기본적으로 원판형 균열(disc fracture)로 가정함.다만 초기 연결 및 평면성 평가 단계에서는 먼저 무한 평면을 피팅하고, 이후 해당 평면 위에서 원판 중심과 반지름을 결정함.
즉, 복원 순서는 다음과 같음.
1. trace 조합으로부터 최적 평면 추정2. 평면 normal vector 계산3. trace 점들을 평면 위 좌표계로 투영4. 투영된 점들을 포함하는 최소 원 또는 robust circle 추정5. 원판 중심과 반지름 결정6. 터널 경계 및 관측 window 효과를 고려해 반지름 보정
2.2.2 원판, 무한 평면, 사각형 중 어떤 방식인가
보고서에서는 다음과 같이 설명하는 것이 적절함.
연결성 평가는 무한 평면 기반으로 수행하고,최종 관찰 균열 복원은 원판형 균열로 수행함.
각 형상의 역할은 다음과 같음.
무한 평면:  trace들이 동일 균열면에 속하는지 평가하기 위한 중간 모델원판:  DFN 생성 및 통계 파라미터 추정에 사용하는 최종 균열 형상사각형:  최종 균열 모델로는 사용하지 않음  단, 계산 효율을 위한 bounding box 또는 후보 탐색 영역으로만 사용 가능
따라서 최종 보고서에는 다음 문장으로 정리 가능함.
본 알고리즘은 trace 연결성 판정을 위해 우선 무한 평면을 피팅하고, 연결이 확정된 trace 집합에 대해 해당 평면상에서 원판형 균열을 복원한다. 사각형은 균열의 물리 형상으로 사용하지 않고, 후보 탐색 및 clipping 계산을 위한 보조 bounding geometry로만 활용한다.
2.2.3 균열 중심점 및 반지름 보정
복원된 원판은 trace 점들을 모두 포함해야 하므로, 최소한 관측 trace endpoint들을 포함하는 크기를 가져야 함.기본 반지름은 평면 위로 투영된 trace endpoint들의 최소 포함 원으로 계산함.
r_obs = max || q_i - c ||
여기서,
q_i = 평면 위로 투영된 trace endpointc   = 원판 중심
하지만 관측 trace는 터널 단면에 의해 절단된 일부만 보이는 것이므로, 실제 균열 반지름은 r_obs보다 클 수 있음.따라서 반지름은 다음 정보를 이용하여 보정함.
1. trace가 터널 경계와 만나는지 여부2. 양 끝이 모두 내부에 있는지, 한쪽만 경계와 만나는지, 양쪽 모두 경계와 만나는지3. 동일 절리군의 반지름 분포 kr4. set-specific effective_rmin5. rmax
현재 파이프라인에서는 반지름 분포 보정을 위해 window-aware Monte Carlo likelihood를 사용함.즉, 관측 trace 길이만 직접 power-law에 피팅하지 않고, 3차원 원판 반지름이 터널 막장 polygon과 교차하여 관측 trace로 나타나는 과정을 전방 모사함.
3. 가상 암반균열망 생성 알고리즘
3.1 절리 전처리
3.1.1 길이, 중심점, 2차원 방향각 계산
각 막장면에서 관측된 trace는 두 endpoint로 주어짐.이를 이용하여 다음 값을 계산함.
trace length:  L = sqrt((y2 - y1)^2 + (z2 - z1)^2)center point:  C = ((y1 + y2)/2, (z1 + z2)/2)2D direction angle:  θ = atan2(z2 - z1, y2 - y1)
여기서 y, z는 막장면 내 local 좌표임.막장면은 굴진 방향에 수직한 단면이므로, trace는 해당 단면상에서 2차원 선분으로 표현됨.
3.1.2 2차원 방향각을 구하는 이유
2차원 방향각은 다음 목적으로 사용됨.
1. 동일 막장면 내 trace 방향성 분류2. 동일 절리군 후보 선별3. 인접 막장면 간 trace 연결 후보 제한4. trace 품질 검토5. 3차원 normal vector 추정의 보조 정보
단일 막장면의 2D trace 방향각만으로는 3D 균열면의 방향을 완전히 결정할 수 없음.그러나 여러 막장면에서 동일 절리군 trace가 반복 관측되면, 막장면 위치 변화와 2D trace 방향의 조합을 통해 3D normal vector, trend, plunge를 추정할 수 있음.
따라서 2D 방향각은 최종 방향성 파라미터가 아니라, 절리군 분류 및 3D 방향성 추정을 위한 관측 feature임.
3.1.3 터널 경계와의 교차 유형 분류
trace endpoint와 터널 단면 polygon의 관계를 이용하여, 각 trace를 다음과 같이 분류함.
Type 0: 내부 trace  양 끝점이 모두 터널 경계 내부에 위치  관측 길이가 실제 chord 길이에 가까움Type 1: 한 끝 교차 trace  한쪽 endpoint가 터널 경계에 접하거나 경계 밖으로 절단됨  실제 chord 길이가 관측 길이보다 길 수 있음Type 2: 양 끝 교차 trace  양쪽 endpoint가 모두 터널 경계와 교차  실제 chord 길이가 관측 길이보다 길 가능성이 큼
이 분류는 trace 길이 분포 보정에 중요함.경계에 의해 잘린 trace를 완전 관측 trace와 동일하게 취급하면, 반지름 분포가 왜곡될 수 있기 때문임.
3.1.4 임계값 이하 짧은 trace 제거
짧은 trace는 다음 이유로 제거함.
1. 이미지 또는 측정 오차에 민감함2. 균열이 아닌 노이즈 또는 미세 파쇄 흔적일 가능성 있음3. 방향각 계산이 불안정함4. power-law 반지름 분포 추정에서 하한부 bias를 유발할 수 있음5. 터널 경계 clipping 효과와 구분이 어려움
현재 단계에서는 임계값이 최적화 완료된 값이라는 의미는 아니며, 분석 안정성을 위한 품질관리 기준으로 사용함.최종적으로는 임계값 민감도 분석을 통해 결정하는 것이 적절함.
보고서 문장은 다음과 같이 작성 가능함.
임계 길이는 균열 통계량의 물리적 하한을 의미하기보다는, 측정 신뢰도가 낮은 짧은 trace와 노이즈성 선분을 제외하기 위한 품질관리 기준으로 설정하였다. 향후 실제 현장 자료 적용 시에는 임계값 민감도 분석을 통해 최종 기준을 결정할 예정이다.
3.2 절리 통계 정보 추출
3.2.1 절리군별 normal vector, trend/plunge 추정
절리군별 방향성은 trace 방향각과 막장면 위치 정보를 이용하여 추정함.여러 막장면에서 동일 절리군 trace가 관측될 경우, 해당 trace들이 놓이는 3차원 평면을 추정하고, 그 평면의 normal vector를 계산함.
평면 normal vector가 계산되면 이를 지질공학적 방향성 표현으로 변환함.
normal vector → trend / plunge
현재 해당 기능은 진행 중이며, 기본 방향은 다음과 같음.
1. trace endpoint를 3D 좌표로 변환2. 동일 절리군 후보 trace 집합 구성3. robust plane fitting 수행4. normal vector 계산5. trend/plunge 변환6. Fisher 또는 von Mises-Fisher 분포로 방향성 분산 추정
3.2.2 절리선 길이 분포 보정
관측 trace 길이는 실제 3D 균열 반지름을 직접 의미하지 않음.큰 균열일수록 막장면에 걸려 관측될 확률이 높고, 터널 경계에 의해 trace가 잘리는 window censoring이 발생하기 때문임.
따라서 단순히 trace 길이에 power-law를 피팅하면 반지름 분포가 왜곡됨.본 연구에서는 다음 보정 방식을 적용함.
1. set-specific effective_rmin 적용2. size-biased radius sampling3. true chord length 생성4. tunnel face polygon clipping5. censoring class 반영6. Monte Carlo likelihood로 kr 추정
현재 구현 및 검증된 핵심 개선 사항은 다음과 같음.
- 모든 set에 동일한 global rmin을 적용하지 않고, set별 effective_generation rmin 사용- proposal_area center weighting 적용- polygon window-aware MC likelihood 적용- bootstrap CI로 kr 불확실성 평가
특히 Laxemar Set 2/3에서 기존에는 kr가 크게 저추정되었으나, set-specific effective_rmin을 적용한 후 nominal kr 근처로 회복됨.이는 반지름 분포 역산에서 support mismatch 보정이 필수적임을 보여줌.
Kaplan–Meier 보정은 trace 길이 censoring을 비모수적으로 보정하기 위한 보조 방법으로 적용 가능함.다만 최종 반지름 분포 추정에는 3D radius-to-trace 관측 과정을 반영한 window-aware Monte Carlo likelihood가 더 직접적이므로, Kaplan–Meier는 비교·진단용 방법으로 활용할 예정임.
3.2.3 연결 성분 분석 및 블록별 묶음
trace 연결 결과는 그래프 구조로 표현할 수 있음.
node:  개별 traceedge:  동일 균열로 연결 가능성이 높은 trace pair
edge weight는 동일 평면성, 방향성 일치도, 거리 연속성 등을 반영함.이후 connected component analysis를 통해 하나의 관찰 균열에 속하는 trace 집합을 묶음.
절차는 다음과 같음.
1. trace를 node로 정의2. 연결 가능성이 있는 trace pair에 edge 생성3. edge score 계산4. score가 임계값 이하인 edge만 유지5. connected component 추출6. component별로 하나의 관찰 균열 후보로 정의7. 각 component에 대해 원판형 균열 복원
이 방식은 여러 막장면에 걸친 동일 균열을 자동으로 묶고, 이후 관측 균열 복원 및 미관측 DFN 생성에 활용할 수 있음.
3.3 가상 암반균열망 생성 알고리즘
3.3.1 생성 영역 구분
가상 암반균열망은 다음 두 영역으로 구분하여 생성함.
1. 관측 균열 복원 영역   - 막장면에서 trace로 관측된 균열을 3D 원판으로 복원   - 연결 알고리즘을 통해 동일 균열 trace를 통합2. 미관측 영역   - trace로 직접 확인되지 않은 터널 전방 및 주변부   - 추정된 DFN 통계 파라미터에 따라 조건부 DFN 생성
관측된 균열은 가능한 한 실제 관측 정보를 유지하여 복원하고, 관측되지 않은 영역은 절리군별 통계 분포를 따르는 확률적 DFN으로 생성함.
3.3.2 DFN 생성 파라미터
절리군별 DFN 생성에는 다음 파라미터가 사용됨.
1. 절리군 방향성   - normal vector   - trend/plunge   - Fisher concentration parameter2. 반지름 분포   - power-law kr   - set_effective_rmin   - rmax3. 강도 파라미터   - P32   - P32_r_ge_effective_support 또는 명시된 P32 support4. 공간 분포   - 균열 중심점의 3D 공간 분포   - 터널 domain 및 관심 영역
현재까지 구현 및 검증된 결과는 다음과 같음.
kr 추정:  effective-rmin + proposal_area window MC 기반으로 안정화P32 추정:  unit_p32_forward_mc calibration 기반 pilot inversion 구현불확실성:  kr bootstrap  face bootstrap  kr × face combined bootstrap
3.3.3 현재 결과 요약
현재까지의 검증 결과를 기준으로, kr 추정은 다음과 같이 분류됨.
kr accepted:  Laxemar Set 1, 2, 3, 5  Forsmark Set 1, 5kr provisional:  Forsmark Set 2kr hold:  Forsmark Set 3, 4  Laxemar Set 4
Laxemar Set 4는 power-law가 아닌 exponential radius distribution이므로, 현재 power-law kr 역산 대상에서 제외함.
P32 pilot 결과는 다음과 같이 분류됨.
P32 final pilot candidate:  Laxemar Set 1, 3, 5P32 candidate with uncertainty:  Forsmark Set 1P32 marginal:  Laxemar Set 2  Forsmark Set 5P32 provisional:  Forsmark Set 2
Laxemar Set 2는 unit-P32 oracle과 trace export audit을 통과했으나, 4개 face에서의 face-level P21 변동성이 커서 marginal로 분류함.Forsmark Set 2는 P32 reference가 bootstrap CI에는 포함되지만, kr 추정 단계에서 systematic bias가 확인되어 provisional로 유지함.
4. 용어 및 계산 정의
4.1 길이
trace 길이는 막장면 local 좌표계에서 양 endpoint 사이의 거리로 계산함.
L = sqrt((y2 - y1)^2 + (z2 - z1)^2)
4.2 중심점
trace 중심점은 두 endpoint의 평균으로 계산함.
C = ((y1 + y2)/2, (z1 + z2)/2)
3D 좌표에서는 해당 막장면의 x 위치를 포함하여 다음과 같이 표현함.
C_3D = (x_face, yc, zc)
4.3 2차원 방향각
2D 방향각은 막장면 local y-z 평면에서 trace가 이루는 각도임.
θ = atan2(z2 - z1, y2 - y1)
2D 방향각은 절리군 분류와 trace 연결 후보 탐색에 사용되며, 최종 3D 방향성은 여러 막장면의 trace 조합으로부터 normal vector를 추정하여 결정함.
4.4 터널 경계 형상
각 막장면의 터널 경계는 2D polygon으로 정의함.trace endpoint가 polygon 내부에 있는지, 경계와 만나는지 여부를 계산하여 censoring class를 결정함.
- 내부 trace- 한 끝 교차 trace- 양 끝 교차 trace
window-aware MC likelihood와 P32 unit-P32 forward MC에서는 동일한 polygon clipping 과정을 적용함.
4.5 임계값
임계 길이는 분석 품질관리를 위한 기준임.현재는 최적화된 물리 상수가 아니라, 짧은 trace의 측정 오차와 방향성 불안정성을 줄이기 위한 필터링 기준으로 사용함.
향후 실제 현장 자료 적용 시에는 다음 방식으로 임계값을 결정할 예정임.
1. 여러 임계값 후보 설정2. kr 추정값 변화 확인3. P32 추정값 변화 확인4. bootstrap CI 변화 확인5. 결과가 안정적인 범위를 최종 임계값으로 선택
5. 최종 정리
본 연구에서는 막장면 trace 자료를 이용하여 3차원 DFN 파라미터를 추정하기 위한 pipeline을 구축하고 있음.현재까지 trace 전처리, 반지름 분포 kr 역산, set-specific effective_rmin 보정, window-aware MC likelihood, P32 unit-P32 forward-MC calibration, bootstrap 기반 불확실성 평가는 구현 및 검증이 완료됨.
관찰 균열 연결 및 최적 평면 복원 알고리즘은 다음 단계에서 구현할 예정이며, 기본 원리는 인접 막장면 trace의 동일 평면성, 방향성 일치도, 절리군 방향성, 반지름 물리 제약을 종합하여 최적 trace 조합을 선정하고, 이를 원판형 3D 균열로 복원하는 방식임.
가상 암반균열망 생성은 관측 trace에서 직접 복원된 균열과, 추정된 DFN 통계 파라미터에 기반한 미관측 영역 확률적 DFN을 결합하는 방식으로 수행할 예정임.
