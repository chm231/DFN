# 제7절 민감도 분석

## 7.0 분석 개요

역산 파이프라인의 **강건성(robustness)** 을 세 축 — (1) DFN 난수 seed, (2) 막장면 굴착 간격, (3) 터널 굴착 각도 — 으로 평가하였다. 각 시나리오마다 동일한 파이프라인

```
DFN 생성 → 막장면 trace 추출 → kr 추정 → 형상 config(κ / trend / plunge) → P32 (unit-P32 forward MC)
```

을 반복 실행하고, 절리군(Set)별 추정치 세 가지를 참값(ground truth, GT)과 비교하였다.

| 지표                 | 의미                    | Laxemar 참값 (Set 1 / 2 / 3 / 5) |
| -------------------- | ----------------------- | -------------------------------- |
| **κ (kappa)** | Fisher 방향 집중도      | 13.06 / 19.62 / 10.46 / 23.52    |
| **kr**         | 반지름 멱법칙 지수      | 2.85 / 3.04 / 3.01 / 3.60        |
| **P32**        | 체적 절리밀도 (m²/m³) | 0.914 / 1.026 / 0.975 / 0.98     |

- **대상 절리군**: 관측 trace 표본이 충분한 Set 1·2·3·5.
- **좌표계**: x = 터널 진행축(East), y = North, z = Up. 막장면 = x = 상수 평면.
- **산포 지표**: 변동계수 **CV = 표준편차 / 평균 × 100(%)**. 편향 = (추정 평균 − GT) / GT × 100(%).

---

## 7.1 DFN seed 민감도 (realization 강건성)

**목적** — 동일한 통계 파라미터로 생성해도 난수 seed에 따라 개별 fracture의 위치·방향 배치가 달라진다. **형상(간격·각도)을 완전히 고정**(터널 방위각 θ = 0°, 막장면 4개)하고 **seed만 30개** 바꿨을 때 추정치가 얼마나 흔들리는지, 그리고 GT를 얼마나 잘 회복하는지를 본다.

![DFN seed 민감도](../storage/output/sensitivity_seed/sensitivity_seed.png)

*그림 7-1. 형상 고정(θ=0°, 막장면 4개) 하에서 realization 30개에 대한 절리군별 κ / kr / P32 분포. 상자=사분위, 검은 선=중앙값, 점=개별 realization, 빨간 점선=ground truth.*

**결과 — 고정 형상에서 seed에 의한 변동(CV)과 GT 대비 편향 (θ=0°, n=30)**

| 지표                       | Set 1           | Set 2           | Set 3          | Set 5          |
| -------------------------- | --------------- | --------------- | -------------- | -------------- |
| **κ** — CV / 편향  | 13.8% / +9.1%   | 19.4% / −5.8%  | 14.6% / +15.1% | 11.9% / +9.0%  |
| **kr** — CV / 편향  | 11.5% / −1.1%  | 13.4% / −4.5%  | 12.5% / −1.2% | 10.3% / −2.7% |
| **P32** — CV / 편향 | 14.2% / −17.0% | 22.1% / −13.8% | 19.0% / −6.7% | 10.8% / −3.2% |

**해석**

- 세 지표 모두 seed에 의한 CV가 **약 10–22%** 로, 단일 realization 추정은 이 정도의 통계적 요동을 내포한다. 따라서 결과는 반드시 **다중 realization 평균 + 산포**로 보고해야 한다.
- **표본이 많은 Set 5가 가장 안정**(모든 지표 CV 최소), **표본이 적은 Set 2가 가장 큰 산포** → 산포는 절리군의 관측 trace 표본 크기에 지배된다.
- 지표별 계통 편향: **kr은 거의 무편향(−1~−5%)** 으로 가장 신뢰도가 높다. **κ는 소폭 과대(+9% 내외, Set 3만 +15%)**, **P32는 소폭 과소(−3~−17%)** 다. P32의 음의 편향은 관측창 절단(짧은 trace) 효과의 잔차로, 표본이 적은 Set 1·2에서 커진다.

## 7.2 막장면 굴착 간격 민감도

**설정** — 막장면 **개수를 4개로 고정**하고 면 간 x 간격 d만 변화시켰다. `d ∈ {0.5, 1, 2, 3, 6} m`, 절리군 {1, 2, 3, 5}, seed 20개 → 총 **400 run**. 개수를 고정하면 **총 관측면적이 간격과 무관하게 일정**하므로, 순수한 공간 상관/독립성 효과만 분리된다(간격 ↓ → 같은 fracture가 인접 면에 상관된 trace 생성, 간격 ↑ → 독립 표본 증가).

![막장면 굴착 간격 민감도](../storage/output/sensitivity_face_interval/sensitivity_face_interval.png)

*그림 7-2. 막장면 굴착 간격 d에 대한 절리군별 κ / kr / P32 boxplot(간격별 20 realization). 빨간 점선=ground truth.*

**결과 — 간격에 의한 변동(구간 평균들 사이의 CV)**

| 지표 | Set 1 | Set 2 | Set 3 | Set 5 |
| ---- | ----- | ----- | ----- | ----- |
| κ   | 2.4%  | 4.1%  | 3.7%  | 5.2%  |
| kr   | 2.6%  | 4.5%  | 1.6%  | 3.8%  |
| P32  | 3.5%  | 2.5%  | 3.0%  | 2.3%  |

**해석**

- **굴착 간격의 영향은 미미하다.** 간격에 의한 변동(1.6–5.2%)은 7.1의 seed 변동(10–22%)보다 **4–5배 작다.** 즉 추정 불확실성은 간격 선택이 아니라 realization 요동이 지배한다.
- κ·kr에서 간격이 커질수록 아주 약한 감소 추세(예: Set 3 κ 12.6 → 11.4, kr 2.94 → 2.82)가 보이나 seed 산포 내에 묻히는 수준으로 **통계적으로 유의하다고 보기 어렵다.**
- **실무적 함의**: 관측 막장면 총면적만 확보되면 굴착 간격(막장 진행 피치)을 넓게 잡아도 파라미터 추정 품질이 사실상 유지된다 → 조사 효율 측면에서 유리하다.

## 7.3 터널 굴착 각도 민감도

**설정** — 코드의 막장면은 항상 x = 상수 평면이므로, "터널을 방위각 θ로 굴착"을 **DFN 전체를 연직 z축 기준 −θ 회전**으로 등가 구현하였다(관측창·거친 막장면 mesh는 고정, fracture 중심·법선만 회전). `θ = 0°–180°, 12° 간격(16개)`, 절리군 {1, 2, 3, 5}, seed 30개 → 총 **1920 run**.

![터널 방위각 민감도 — κ](../storage/output/sensitivity_tunnel_angle/sensitivity_kappa.png)

*그림 7-3a. 터널 방위각 θ에 대한 Fisher 집중도 κ (각도별 30 realization). 빨간 점선=ground truth.*

![터널 방위각 민감도 — kr](../storage/output/sensitivity_tunnel_angle/sensitivity_kr_hat.png)

*그림 7-3b. 터널 방위각 θ에 대한 반지름 멱법칙 지수 kr.*

![터널 방위각 민감도 — P32](../storage/output/sensitivity_tunnel_angle/sensitivity_P32_hat.png)

*그림 7-3c. 터널 방위각 θ에 대한 체적 절리밀도 P32.*

**결과 — 각도에 의한 변동(각도별 평균들 사이의 CV)과 GT 대비 편향**

| 지표 | Set 1 | Set 2 | Set 3 | Set 5 | GT 대비 편향              |
| ---- | ----- | ----- | ----- | ----- | ------------------------- |
| κ   | 6.2%  | 7.1%  | 8.0%  | 3.5%  | +4 ~ +12% (경미한 과대)   |
| kr   | 3.1%  | 1.3%  | 1.3%  | 3.3%  | ±3% 내 (거의 무편향)     |
| P32  | 4.3%  | 6.4%  | 2.2%  | 2.1%  | −5 ~ −17% (경미한 과소) |

(예: Set 2 κ의 각도별 평균은 17.06–22.95 범위에서 GT 19.62 주변을 진동한다.)

**해석**

- **각도 의존성은 존재하나 작다.** 각도에 의한 변동(1.3–8.0%)은 seed 변동보다 작고, GT를 중심으로 진동할 뿐 계통적 왜곡은 없다 → 역산이 **터널 방향에 대해 대체로 불변(orientation-robust)** 함을 확인.
- 절리군 평균 방향이 막장면과 **저각(low-angle)으로 만나는 θ 부근**에서 trace가 짧고 드물어져 κ 산포가 커진다(κ의 각도 CV가 세 지표 중 최대). 반대로 **Set 5는 전 각도에서 안정적**(κ 각도 CV 3.5%)이다.
- 지표별 계통 편향 경향은 7.1과 동일하다: **kr 거의 무편향, κ 소폭 과대(+), P32 소폭 과소(−)**.

---

## 7.4 종합

1. **지배 불확실성은 seed(realization) 요동(CV 10–22%)** 이며, 굴착 간격·각도 등 기하 조건의 영향(대개 < 8%)은 그보다 뚜렷이 작다.
2. 따라서 역산 결과는 **다중 realization 평균 + 신뢰구간** 형태로 보고해야 하며, 단일 realization 값에 과도한 의미를 부여해선 안 된다.
3. 파이프라인은 **굴착 간격·터널 방향에 대해 강건**하다. 계통 편향은 **kr ≈ 무편향, κ 소폭 과대, P32 소폭 과소** 로 일관된다.
4. 모든 지표에서 **표본이 많은 Set 5가 가장 안정, 표본이 적은 Set 2가 가장 불안정** → 추정 품질은 절리군별 관측 trace 표본 크기에 의해 결정된다.
