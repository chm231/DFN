## 15. 절리선 relink(조각 이어붙이기) 실험 (09-03)

가설(사용자): 같은 절리의 조각들을 병합하면 kr이 작아지고 복원 반경·도달거리가
늘 것. 검증 절차: 동일선상(오프셋<5cm, 방향<2.5°)·간격≤tol 연쇄 병합 → kr 재적합
→ P32 재보정(lmin0.5) → 면08 블라인드(모델·실측 양쪽 relink 공정 비교).

- 조각 후보: gap<0.1m 479쌍(7.4%)~0.5m 1,376쌍(21%). 6면 데이터 tol0.2에서
  4,551→3,952개.
- **kr 스윕(면1~6)**: tol 0/0.1/0.2/0.3 → set1 4.00/3.90/3.75/3.85,
  set2 3.80/3.65/3.55/3.55, set3 3.65/3.55/3.55/3.45. Δkr −0.10~−0.25 확인.
  복원 반경 E[r|h]=(kr−1)/(kr−2)·h 로 ~5~8%↑.
- **블라인드 판정: 채택 근거 없음** — 양쪽 relink 공정 비교에서 개수 126 vs 160
  (−21%, 기존 −18%), P21 2.24 vs 2.54(90백분위, 기존 80), 길이 중앙값 격차 유지.
  relink가 모델·실측을 같은 비율로 밀어 상대 정합 불변. 반전: 실측 개수는 병합에도
  139→160 증가(0.5m 미만 조각 병합이 문턱을 넘어옴).
- **결론: 기각(사용자 확정)** — kr 변화는 "길이 정의" 변경이며 파이프라인은 정의 일관 시 자기보정 →
  기본값 유지(relink 미채택). 잔차(모델이 적고 긴 절리선)는 별도 원인(kr 미세
  과소 or 검열 처리). 도구 보존: scripts/analysis_260903/relink_h5_full.py·relink_traces.py(완전 스키마, 임의 tol — repo 이관), kr_relink/ 스윕 결과, (조립 파이프라인 dir은 기각 후 삭제 — 로그의 절차로 재구성 가능),
  slide/f08_rl02(MC npz), relink12_tol0.2.h5(12면 relink).
