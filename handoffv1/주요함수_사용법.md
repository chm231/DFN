# 주요 함수·사용 방법 정리 (handoffv1)

패키지 사용 방법은 세 층위로 나뉩니다. 자세한 설치·데모 실행은 `README_DEMO.md`,
파일별 역할·정책은 `README.md`를 보세요. 이 문서는 **어떤 함수를 어떻게 호출하는지**를
단계별로 정리한 API/CLI 요약입니다.

- 좌표 규약: **x = East = 터널 진행축, y = North, z = Up**. 막장면 = x = 상수 평면.
- 모든 모듈 CLI는 `python -m dfn_analysis.<모듈> --help` 로 전체 옵션을 확인할 수 있습니다.
- 모듈 실행 시 작업 폴더는 `handoffv1/` 루트여야 하며 `PYTHONPATH=.` 이 필요합니다
  (`run_demo.py`가 자동으로 설정).

---

## 0. 전체 파이프라인 한 번에 — `run_demo.py`

```
.venv\Scripts\python.exe run_demo.py --seed 42 --n-bootstrap 0 --skip-3d   # 빠른 실행(~30초)
.venv\Scripts\python.exe run_demo.py --seed 42                             # 전체(수 분)
```

시드 42 = 보고서 표 6-5 벤치마크 재현(절리선 수 170/39/132/171).
내부적으로 아래 1~9단계 모듈을 순서대로 subprocess 호출하므로, 단계별 명령은
실행 로그의 `$ ...` 줄을 그대로 복사해 개별 재실행할 수 있습니다.

## 1. 합성 DFN 생성 — `dfn generator v1/python/generate_dfn.py`

```
python "dfn generator v1/python/generate_dfn.py" --site laxemar --seed 42 --output-dir <outdir>
```
출력: `<outdir>/dfn_export_for_python.h5` (`/fractures/centers·normals·radii·set_id`).
실측 데이터로 시작하는 경우 이 단계는 건너뛰고, 같은 스키마의 h5만 준비하면 됩니다.

## 2. 막장면 절리선 데이터셋 — `export_flat_face_traces`

```
python -m dfn_analysis.export_flat_face_traces --dfn-h5 <dfn.h5> --face-x 0 1 2 3 --outdir <trace_dir>
```
출력: `trace_dataset_3d.h5` + 면별 csv. 관측면적 `/meta/observation_area_m2` 포함(P32에서 사용).

| 함수 | 용도 |
|---|---|
| `disc_plane_chords(centers, normals, radii, face_x)` | 원판×평면 교차 → 현(chord) 중점·방향·길이 |
| `clip_chords_to_polygon(mid_yz, dir_yz, true_len, polygon_yz)` | 현을 터널 단면 다각형으로 클리핑 |
| `classify_endpoints(pts_yz, polygon_yz)` | 끝점 censoring 분류 (양끝/한끝/무절단) |

## 3. 방향·kappa 추정 (라이브러리 모듈, CLI 없음)

`estimate_mean_orientation.py` / `estimate_fisher_kappa.py`는 import 전용 기반 모듈입니다.

| 함수 | 용도 |
|---|---|
| `estimate_mean_normal_axial(normals_xyz)` | 법선 집합의 축성(axial) 평균 방향 (n×3 → 단위벡터) |
| `normal_to_trend_plunge_ned(normal_xyz)` | 법선 → 지질 방위각 trend/plunge (NED 규약) |
| `estimate_fisher_k_axial(normals_xyz)` | Fisher 집중도 κ 추정 (dict 반환: kappa, Rbar, n) |
| `estimate_trace_normal_3pt(...)` | polyline 3점법 trace 법선 (legacy — v1 기본은 외부 3D 방향) |

```python
from dfn_analysis.estimate_mean_orientation import estimate_mean_normal_axial, normal_to_trend_plunge_ned
from dfn_analysis.estimate_fisher_kappa import estimate_fisher_k_axial
mean_n = estimate_mean_normal_axial(normals_xyz)      # (N,3) ndarray
trend, plunge = normal_to_trend_plunge_ned(mean_n)
kappa = estimate_fisher_k_axial(normals_xyz)["kappa"]
```

## 4. 반지름 멱법칙 지수 k_r 역산 — `estimate_kr`

```
python -m dfn_analysis.estimate_kr --trace-h5 <trace.h5> --site laxemar \
  --target-set 1 2 3 5 --outdir <kr_dir> [--run-bootstrap --n-bootstrap 100]
```
출력: `kr_summary_by_set.csv` (이후 단계의 공통 입력).
기본 우도 `--likelihood-mode hybrid`(v1 최종). 임의 데이터셋은 `--site` 대신
`--dfn-model <라벨> --generation-rmin <값>` 사용.
핵심 우도 계산은 `estimate_radius_powerlaw_window_mc.py`에 있으며 직접 호출할 일은 거의 없습니다.

## 5. dataset config 자동 생성 — `build_dataset_config_from_traces`

```
python -m dfn_analysis.build_dataset_config_from_traces --trace-h5 <trace.h5> \
  --kr-summary-csv <kr_summary.csv> --dataset-name my_dataset --target-set 1 2 5 --out <config.json>
```
trace의 법선(`trace_normal_xyz`)에서 set별 trend/plunge/κ를 추정해 P32용 config JSON을 만듭니다.
config 스키마·수동 작성법은 `README.md`의 "P32용 데이터셋 config" 절 참조.
`dataset_config.load_and_register(path)`가 이 JSON을 런타임 preset으로 등록하는 API입니다.

## 6. P32 역산 — `estimate_p32_mc_calibrated`

```
python -m dfn_analysis.estimate_p32_mc_calibrated --trace-h5 <trace.h5> --site laxemar \
  --target-set 1 2 3 5 --kr-summary-csv <kr.csv> --dfn-h5 <dfn.h5> --outcsv <p32.csv> \
  [--config <config.json>]        # 지정 시 역산 방향분포 사용(자기완결)
```
출력: `p32_summary.csv` (P32_hat = observed_P21 / C).
기본·최종 모드 `--calibration-factor-mode analytic_esinphi`: C = E[sinφ] 결정론적 구적.

| 함수 | 용도 |
|---|---|
| `analytic_esinphi_calibration(site, set_id, ...)` | 환산계수 C = E[sinφ] 해석식 계산 |
| `load_p21_summary(trace_h5, ...)` | 관측 P21 집계 (관측면적은 h5 meta 우선) |
| `powerlaw_moment(kr, rmin, rmax, order)` | 멱법칙 반지름 모멘트 (지지구간 스케일링용) |

## 7. 관측 균열 복원 (trace → 원판) — `reconstruct_discs_from_traces`

```
python -m dfn_analysis.reconstruct_discs_from_traces --trace-h5 <trace.h5> \
  --kr-summary-csv <kr_summary.csv> --out-csv <reconstructed_discs.csv> [--target-set 1 2 3 5]
```
자립적 모듈(numpy/scipy/h5py만). 출력 csv의 `radius_status`:
determined(원적합) / shrinkage(kr 축소추정) / lower_bound(하한).

| 함수 | 용도 |
|---|---|
| `reconstruct(trace_h5, association, angle_deg, coplanar_m, max_sep_m, ...)` | 전체 복원 파이프라인 (연결→평면적합→반지름) |
| `associate_agglomerative(traces, ...)` | 검증형 응집 연결 (기본, oracle 대비 순도 ~95%) |
| `radius_posterior_mean(a, kr, rmax)` | kr 사전분포 기반 반지름 축소추정 (empirical-Bayes) |
| `load_traces(trace_h5)` | trace h5 → 면별 trace 목록 로드 |

## 8. 조건부 암반균열망 생성 — `generate_conditional_hidden_dfn`

```
python -m dfn_analysis.generate_conditional_hidden_dfn --pipeline-dir <base> \
  --rmax-local 25 --lmin-det 0.5 --seed 42
```
`--pipeline-dir`는 1~7단계 출력이 모인 폴더(run_demo의 `demo_output/seed<시드>`).
출력: `conditional_hidden/conditional_dfn.csv` (visible+hidden) + set별 P21 진단표.

| 함수 | 용도 |
|---|---|
| `generate_hidden_discs(...)` | 역산 파라미터(P32, kr, Fisher)로 확률 균열 생성 |
| `remove_face_intersecting(...)` | 관측 막장면과 모순(검출됐어야 할) hidden 균열 제거 |
| `visible_trace_on_face(...)` | 원판×막장면 chord를 터널 단면으로 클리핑 (검증·시각화 공용 기하) |
| `load_inverted_params(kr_csv, p32_csv)` | kr/P32 역산 결과 csv → set별 파라미터 dict |

## 9. 안정성 해석 입력 JSON — `export_domain_dfn_json`

```
python -m dfn_analysis.export_domain_dfn_json --pipeline-dir <base> \
  --rmax-local 25 --lmin-det 0.5 --seed 42
```
출력: `export/dfn_domain_x<범위>_halo<값>.json` — 도메인(관측면 이후 x구간 + 단면 halo)과
교차하는 균열만 선별(`select_intersecting`), 관측/미관측 구분(`observed` 플래그) 포함.
표 6-4 형식으로 블록 생성·안정성 해석 모듈에 전달하는 최종 산출물입니다.

## 10. 검증·시각화

```
python -m dfn_analysis.validate_reconstruction_lofo --trace-h5 <trace.h5> ...   # LOFO 외삽검증 (참값 불필요)
python -m dfn_analysis.visualize_reconstruction ...                             # 관측 trace vs 복원 chord
python -m dfn_analysis.plot_domain_dfn_3d --json <export.json> --out-dir <dir>  # 도메인 3D (pyvista)
python -m dfn_analysis.visualize_conditional_dfn_3d ... [--html]                # 조건부 DFN 3D
python scripts/compare_pipeline_to_laxemar.py --base <base>                     # 참값 대비 비교표
```
LOFO 핵심 함수: `validate_reconstruction_lofo.lofo(trace_h5, kr_map, target_sets, ...)` —
한 면을 빼고 복원 → 그 면의 관측을 recall/precision으로 채점.

## 실측 데이터 적용 시 최소 경로

1. 실측 trace를 `trace_dataset_3d.h5` 스키마로 준비 (2단계 출력 형식; set_id, 끝점, 법선, 관측면적 meta)
   - **DFM Viewer 추출본은 변환기가 있음**: `scripts/convert_dfm_export_to_trace_dataset.py`
     (`--dfm-dir <DFM_Export> --outdir <출력>`) — 터널축 정렬, 면별 DS→전역 절리군 재분류,
     점군 기반 관측면적·관측창 산정, 조건부 단계용 보조 h5 생성까지 자동. 2026-08 실측
     막장면 12개 데모에서 검증(보고서: `docs/DFM샘플데이터_파이프라인_데모보고서.md`).
2. `estimate_kr` (4) → `build_dataset_config_from_traces` (5) → `estimate_p32_mc_calibrated --config` (6)
3. `reconstruct_discs_from_traces` (7) → `generate_conditional_hidden_dfn` (8) → `export_domain_dfn_json` (9)

### 파서(CLI 옵션)로 조정 가능한 주요 파라미터

막장면 개수·위치를 포함해 아래 파라미터는 **코드 수정 없이 명령줄 옵션으로 변경**할 수 있습니다.
현장 조건(막장면 수, 터널 단면, 절리군 구성)이 벤치마크와 달라도 옵션 지정만으로 실행됩니다.

| 파라미터 | 옵션 | 모듈 | 비고 |
|---|---|---|---|
| **막장면 개수·위치 [m]** | `--face-x x1 x2 ...` | `export_flat_face_traces`, `run_demo.py` | 개수 제한 없음. 예: `--face-x 0 0.8 1.6 2.4 3.2` (5개면) |
| 터널 단면 다각형 | `--tunnel-dat <파일>` | `export_flat_face_traces`, `estimate_kr` | trace h5에 `/meta/tunnel_poly_yz`가 없을 때 지정 |
| 대상 절리군 | `--target-set` (4·6·7) / `--sets`, `--exclude-sets` (8·9) | 각 단계 공통 | 8·9단계 기본값 = 역산 파라미터가 있는 전체 set |
| 검출 하한 [m] | `--lmin` (2) / `--lmin-det` (8·9) | 절리선 추출 / 조건화 | 관측 모순 판정 기준 |
| 반지름 생성 구간 [m] | `--rmin`, `--rmax`, `--generation-rmin`, `--generation-rmax` | `estimate_kr` | 임의 데이터셋은 `--site` 대신 `--dfn-model <라벨>` |
| kr 탐색 범위·우도 | `--kr-min`, `--kr-max`, `--likelihood-mode` | `estimate_kr` | 기본 hybrid(v1 최종) |
| P32 환산계수 모드 | `--calibration-factor-mode` | `estimate_p32_mc_calibrated` | 기본 `analytic_esinphi`(최종) |
| 복원 연결 허용오차 | `--normal-angle-deg`, `--coplanar-dist`, `--max-centroid-sep`, `--arc-min` | `reconstruct_discs_from_traces` | 연결 방식은 `--association` |
| 복원 반지름 모드 | `--radius-mode {mean,sample}`, `--radius-seed` | `reconstruct_discs_from_traces` | sample=사후분포 표본+현 보존 배치(안정성 해석 입력 권장), mean=사후평균(기존) |
| 조건부 생성 범위 | `--rmax-local`, `--margin`, `--seed` | `generate_conditional_hidden_dfn` | |
| 해석 도메인 | `--halo`, `--ahead`, `--x-range`, `--tunnel-x-range`, `--domain-shape` | `export_domain_dfn_json` | 도메인 = 단면 halo × x구간 |

각 모듈의 전체 옵션 목록·기본값은 `python -m dfn_analysis.<모듈> --help` 로 확인하세요.

주의: set 구성은 위 옵션으로 조정 가능하지만, **지수분포 반지름 set**(예: Laxemar Set 4)은
멱법칙 기반 k_r/P32 역산·조건화 대상에서 제외해야 합니다(정책 D002 — `--target-set`/`--exclude-sets`로 제외).
