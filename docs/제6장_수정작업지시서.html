H-3. P32 보정계수 재정의 — 순수 해석식에서 $C_{\ell_{\min}}$으로

H-3.1 무엇이 바뀌는가

샌드박스 문서는 "P32의 최종 기본 모드를 순수한 analytic_esinphi로 확정한 부분은 수정해야 한다"고 명시한다. $E[\sin\phi]$는 방향 보정의 해석적 성분으로만 쓰고, 최소 길이·관측창 효과는 MC 보정으로 남긴다.

$$\boxed{\,C_{\ell_{\min}}=E[\sin\phi]\cdot\eta_{det}\,},\qquad \boxed{\,\widehat{P_{32}}=\frac{P_{21,obs}^{ret}}{C_{\ell_{\min}}} =\frac{P_{21,obs}^{ret}}{E[\sin\phi]\,\eta_{det}}\,}$$

$$P_{21,obs}^{ret}=\frac{\sum_i \ell_i\,\mathbf{1}(\ell_i\ge\ell_{\min})}{A_{obs}}, \qquad \eta_{det}=\frac{E\big[\ell_{vis}\mathbf{1}(\ell_{vis}\ge\ell_{\min})\big]}{E[\ell_{vis}]}$$

  • $E[\sin\phi]$ : 방향에 따른 기본 교차효율 (평균 방향·$\kappa$·막장면 법선에 의존)
  • $\eta_{det}$ : 터널 경계 clipping·최소 길이·검출 누락·반지름 분포 적용 후 유지되는 기대 길이 비율
  • 핵심 원칙: 관측자료와 보정계수 산정용 가상자료에 동일한 $\ell_{\min}$을 적용한다.

실무 지침(샌드박스 §5): 두 성분을 분리해 구할 필요는 없고, 관측과 동일한 절차를 적용한 순방향 모사에서 $C_{\ell_{\min}}$을 직접 계산하는 편이 단순·안전하다.

H-3.2 8단계 산정 절차 (보고서 제3절 3 대체 서술의 뼈대)

단계 처리 내용
1 절리군별 입력값 설정 평균 방향 또는 절리선별 법선, $\kappa$, 추정 $k_r$, 유효 $r_{\min}$·$r_{\max}$, 터널 단면 polygon, 막장면 면적, $\ell_{\min}$
2 $P_{32}=1$ 기준 균열망 정의 $n_0=1/(\pi E[R^2])$
3 기준 균열망 생성 반지름 분포 + Fisher 방향 + 공간 Poisson 배치
4 막장면 교차·clipping 현 생성 후 터널 단면 polygon으로 절단 → $\ell_{vis}$
5 동일한 $\ell_{\min}$ 적용 실제 자료와 같은 임계값을 가상 절리선에도 적용
6 가상 $P_{21}$ 계산 임계값 통과분 합 / 총 관측면적
7 $C$ 산정 및 반복 평균 $C^{(b)}=P_{21}^{sim,ret(b)}/P_{32}^{sim(b)}$, $\bar C=\frac1B\sum_b C^{(b)}$
8 관측 $P_{32}$ 역산 $\widehat{P_{32}}=P_{21,obs}^{ret}/\bar C$

반복(B회)의 이유: 시드에 따른 실현 변동 때문. $s^2(C)=\frac{1}{B-1}\sum_b(C^{(b)}-\bar C)^2$ 로 분산을 구하고, $k_r$·방향 분포 불확실성과 함께 반영해 $P_{32}$ 신뢰구간을 산정한다.

H-4. 파급 효과와 필요 작업 — ⚠ 반드시 확인할 것

① 요철 mesh 삭제가 기존 "알려진 한계" 두 건을 해소한다 (긍정적 파급)

현재 코드에서 확인된 사실: 관측 $A_{obs}$는 mesh 삼각형 면적 합 (compute_total_observation_area(rough_faces))인 반면, 시뮬레이션 쪽 면적은 polygon shoelace 면적이다. 이 기준 불일치가 종전에 규명한 두 문제의 근원이었다.

  • $\eta_{win}=1.02\sim1.04$ 아티팩트 (통합본 §2.5, mesh가 polygon보다 −3.85%)
  • v1 알려진 한계: $k_r$ 모델 창(다각형) vs 관측 footprint(mesh) 불일치 — 기준 일치 실험에서 전 절리군 $k_r$ 오차 ≤0.04로 회수됨 (통합본 §4.7)

막장면이 평면이 되면 $A_{obs}$ = polygon 면적이 되어 두 기준이 자동 일치하므로, 위 두 한계가 함께 사라진다. 즉 이번 범위 축소는 서술 단순화일 뿐 아니라 정확도 개선 요인이다. → 보고서 제6절 4(한계)에서 해당 한계 서술을 삭제할 수 있게 될 가능성이 높다(재실행으로 확인 필요).

② 코드 미구현 — $C_{\ell_{\min}}$은 현재 어느 모드에도 없다

estimate_p32_mc_calibrated.py를 확인한 결과 $\ell_{\min}$ 관련 처리가 전무하다 (관측 $P_{21}$·시뮬 $P_{21}$ 모두 필터 없음). 따라서:

  • analytic_esinphi = $E[\sin\phi]$만 → $\eta_{det}$ 누락
  • unit_p32_forward_mc = MC지만 $\ell_{\min}$ 미적용 + 면적 기준 불일치

둘 다 샌드박스 정의를 만족하지 못한다. 신규 모드(예: analytic_esinphi_x_eta_det 또는 forward_mc_lmin) 구현이 필요하다. 구현 범위: (a) 관측 $P_{21}$에 $\ell_{\min}$ 필터, (b) 시뮬 쪽 동일 필터, (c) 평면 막장면 기준 $A_{obs}$, (d) B회 반복 평균·분산 출력.

③ 검증 수치 재실행 범위 — 결정 필요

현재 v1 수치(표 6-5, 표 6-3, 제7절 민감도 표 3종·그림 5장)는 전부 요철 mesh 기반이다. 평면 막장면으로 바꾸면 값이 이동한다. 두 선택지:

  • (a) 평면 막장면으로 전면 재실행 — 보고서 서술과 검증 조건이 일치하고, ①의 한계 해소 효과까지 수치로 확인된다. 비용: 검증표 ~5분 + 민감도 스윕 ~51분 + 복원 ~1분 (측정치 기준). 권고안.
  • (b) 현 수치 유지 + 각주 — "검증용 합성 절리선은 요철 막장면과의 교차로 생성했다"고 검증 절에만 각주. 서술과 수치의 괴리가 남고 ①의 이득도 못 얻음.

→ (a)를 권고한다. 특히 $k_r$ 정확도가 크게 개선될 것으로 예상되며(오차 ≤0.04 회수 실험 근거), 이는 표 6-5와 제6절 3(해석) 서술을 유리하게 바꾼다.
