4. p.37 본문 "역산 결과는 표 6-4와 같다" → **표 6-5**

    k_r 미보유라 전부 하한값)으로 보임 → 좌/우가 뒤바뀐 것으로 판단됨. v1 교체 그림
    기준으로는 set 4 = 흰색 위주, set 5 = 주황+초록이므로 캡션과 패널을 맞춰 배치할 것

## H-3. P32 보정계수 재정의 — 순수 해석식에서 $C_{\ell_{\min}}$으로

### H-3.1 무엇이 바뀌는가

샌드박스 문서는 **"P32의 최종 기본 모드를 순수한 `analytic_esinphi`로 확정한 부분은
수정해야 한다"**고 명시한다. $E[\sin\phi]$는 **방향 보정의 해석적 성분**으로만 쓰고,
**최소 길이·관측창 효과는 MC 보정으로 남긴다.**

$$\boxed{\,C_{\ell_{\min}}=E[\sin\phi]\cdot\eta_{det}\,},\qquad
\boxed{\,\widehat{P_{32}}=\frac{P_{21,obs}^{ret}}{C_{\ell_{\min}}}
=\frac{P_{21,obs}^{ret}}{E[\sin\phi]\,\eta_{det}}\,}$$

$$P_{21,obs}^{ret}=\frac{\sum_i \ell_i\,\mathbf{1}(\ell_i\ge\ell_{\min})}{A_{obs}},
\qquad
\eta_{det}=\frac{E\big[\ell_{vis}\mathbf{1}(\ell_{vis}\ge\ell_{\min})\big]}{E[\ell_{vis}]}$$

- $E[\sin\phi]$ : 방향에 따른 기본 교차효율 (평균 방향·$\kappa$·막장면 법선에 의존)
- $\eta_{det}$ : 터널 경계 clipping·최소 길이·검출 누락·반지름 분포 적용 후 **유지되는
  기대 길이 비율**
- **핵심 원칙: 관측자료와 보정계수 산정용 가상자료에 동일한 $\ell_{\min}$을 적용한다.**

실무 지침(샌드박스 §5): 두 성분을 **분리해 구할 필요는 없고**, 관측과 동일한 절차를
적용한 순방향 모사에서 $C_{\ell_{\min}}$을 **직접** 계산하는 편이 단순·안전하다.

### H-3.2 8단계 산정 절차 (보고서 제3절 3 대체 서술의 뼈대)

| 단계 | 처리 | 내용 |
|---|---|---|
| 1 | 절리군별 입력값 설정 | 평균 방향 또는 절리선별 법선, $\kappa$, 추정 $k_r$, 유효 $r_{\min}$·$r_{\max}$, 터널 단면 polygon, 막장면 면적, $\ell_{\min}$ |
| 2 | $P_{32}=1$ 기준 균열망 정의 | $n_0=1/(\pi E[R^2])$ |
| 3 | 기준 균열망 생성 | 반지름 분포 + Fisher 방향 + 공간 Poisson 배치 |
| 4 | 막장면 교차·clipping | 현 생성 후 터널 단면 polygon으로 절단 → $\ell_{vis}$ |
| 5 | **동일한 $\ell_{\min}$ 적용** | 실제 자료와 같은 임계값을 가상 절리선에도 적용 |
| 6 | 가상 $P_{21}$ 계산 | 임계값 통과분 합 / 총 관측면적 |
| 7 | $C$ 산정 및 반복 평균 | $C^{(b)}=P_{21}^{sim,ret(b)}/P_{32}^{sim(b)}$, $\bar C=\frac1B\sum_b C^{(b)}$ |
| 8 | 관측 $P_{32}$ 역산 | $\widehat{P_{32}}=P_{21,obs}^{ret}/\bar C$ |

반복(B회)의 이유: 시드에 따른 실현 변동 때문. $s^2(C)=\frac{1}{B-1}\sum_b(C^{(b)}-\bar C)^2$
로 분산을 구하고, $k_r$·방향 분포 불확실성과 함께 반영해 $P_{32}$ 신뢰구간을 산정한다.

## H-4. 파급 효과와 필요 작업 — ⚠ 반드시 확인할 것

### ① 관측면적 기준 불일치의 진짜 원인 — ⚠ 최초 진단 정정

관측 $A_{obs}$는 **mesh 삼각형 면적 합**(`compute_total_observation_area`)인 반면
시뮬레이션 쪽은 **polygon shoelace 면적**이라는 기준 불일치가 있고, 이것이 종전에
규명한 두 문제($\eta_{win}$ 아티팩트, $k_r$ 창/footprint 불일치)의 근원이라는 판단은
맞다. **다만 그 −3.85%의 원인을 "요철" 때문으로 본 최초 진단은 틀렸다.**

측정으로 확인한 결과:

| 항목 | 1면 면적 (m²) | 다각형(73.9266) 대비 |
|---|---|---|
| 다각형(정확) | 73.9266 | — |
| 평면 mesh, grid_step 0.2 m | 71.0800 | **−3.85%** |
| 평면 mesh, grid_step 0.1 m | 72.4700 | −1.97% |
| 평면 mesh, grid_step 0.05 m | 73.2325 | −0.94% |
| 요철 mesh, grid_step 0.2 m | 71.4156 | −3.40% |

즉 −3.85%는 **격자 이산화로 경계가 계단형이 되어 생기는 손실**이며(격자를 절반으로
줄일 때마다 오차도 절반 → $O(h)$ 수렴), 요철의 기여는 표면적 증가 **+0.47%**로 반대
부호의 작은 항이다. **따라서 "평면화하면 자동으로 해소된다"는 것은 성립하지 않는다.**

**실제 해법**: mesh를 쓰지 않고 **터널 단면 다각형 자체를 관측면으로** 삼는다. 평면
막장면에서는 원판–평면 교선을 해석적으로 구해 다각형으로 정확히 클리핑할 수 있으므로
mesh가 애초에 불필요하다 → 신규 모듈 `dfn_analysis/export_flat_face_traces.py`.
이렇게 하면 $A_{obs}$ = 다각형 면적 × 막장면 수가 되어 모델 창 기준과 **정확히** 일치한다.
결과는 H-6 참조(실측 개선 확인).

### ② 코드 미구현 → ✅ 구현 완료

`estimate_p32_mc_calibrated.py`를 확인한 결과 **$\ell_{\min}$ 관련 처리가 전무**하다
(관측 $P_{21}$·시뮬 $P_{21}$ 모두 필터 없음). 따라서:

- `analytic_esinphi` = $E[\sin\phi]$만 → $\eta_{det}$ 누락
- `unit_p32_forward_mc` = MC지만 $\ell_{\min}$ 미적용 + 면적 기준 불일치

**둘 다 샌드박스 정의를 만족하지 못했다.** → 신규 모드 **`forward_mc_lmin`(현 기본값)**
을 구현했다(커밋 `e217551`, 루트·handoff·handoffv1 동시 반영):

- 관측 $P_{21}^{ret}$: `--lmin` 이상 절리선만 집계
- 가상 $P_{21}^{sim,ret}$: 순방향 모사의 가시길이에 **동일한** `--lmin` 적용
- $A_{obs}$: trace HDF5의 `/meta/observation_area_m2`(다각형 면적×막장면 수) 우선,
  없으면 legacy mesh 면적으로 폴백
- $C^{(b)}$를 B회 반복(`--unit-p32-mc-replicates`, 기본 32) 평균·분산 → 신뢰구간

두 성분($E[\sin\phi]$, $\eta_{det}$)을 분리 산정하지 않고 $C_{\ell_{\min}}$을 직접
계산한다(샌드박스 §5 권고).
