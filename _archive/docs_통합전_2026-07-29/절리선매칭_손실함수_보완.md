# 절리선 쌍 매칭 손실함수 — 설명 보완 (다음 미팅 공유용 초안)

> 대상: 보고서 제6장 제4절 「관측 균열 연결 및 복원」의 식 6.15(정합 점수 S).
> 목적: 보고서의 **가중합 손실 S = Σ wᵢ Eᵢ** 서술과 **실제 구현**(`reconstruct_discs_from_traces.py`
> 의 기본 모드 `agglomerative`)의 판정 방식이 달라, 실제 로직을 정확히 문서화한다.

---

## 1. 요점 — 보고서와 구현의 차이

보고서 식 6.15는 후보 조합의 정합도를 **하나의 스칼라 가중합**으로 정의하고
임계값 이하만 연결한다고 서술한다:

$$ S = w_1 E_{plane} + w_2 E_{direction} + w_3 E_{normal} + w_4 E_{radius} + w_5 E_{con}, \quad S \le \tau. $$

그러나 최종 구현은 **가중합 스칼라 S를 만들지 않는다.** 대신
(1) 후보쌍을 **하드 게이트**로 먼저 거르고,
(2) 근접순으로 **증분(agglomerative) 병합**하되, 매 병합마다 **두 개의 하드 수용 검사**를
통과할 때만 확정한다.

이 방식은 튜닝 가중치 $w_i$·임계값 $\tau$ 하나로 모든 항을 뭉뚱그리는 대신, 물리적으로
해석 가능한 개별 조건을 순차 적용한다. 결과적으로 **자유 가중치가 없어** 과적합·과대병합에
강하고, oracle(참 fracture_id) 대비 trace 순도 ≈ 95%를 얻는다.

---

## 2. 실제 판정 함수 (모드: `agglomerative`, 기본값)

절리선 $i$는 3D polyline 점집합 $V_i$, 국소 단위 법선 $\hat n_i$, 중심(centroid) $c_i$,
막장면 위치 $x_i$, 중점 $m_i$, 소속 set $s_i$ 를 갖는다.

### 2.1 1단계 — 후보 간선 게이트 (pairwise gate)

두 절리선 $(i,j)$는 **다음 네 조건을 모두** 만족할 때만 병합 후보가 된다.

| 기호 | 조건 | 식 | 기본값 |
|------|------|----|--------|
| — | 동일 절리군 | $s_i = s_j$ | — |
| $E_{normal}$ 대응 | 법선 축각 | $\angle_{ax}(\hat n_i,\hat n_j)=\arccos\lvert \hat n_i\!\cdot\!\hat n_j\rvert \le \theta_{ang}$ | 15° |
| $E_{plane}$ 대응(후보 수준) | 상호 공면 거리 | $\max\big(\lvert (c_j-c_i)\!\cdot\!\hat n_i\rvert,\ \lvert (c_i-c_j)\!\cdot\!\hat n_j\rvert\big) \le d_{cop}$ | 0.15 m |
| — | 중심 근접 | $\lVert c_i-c_j\rVert \le s_{max}$ | 2.0 m |

- 법선은 축성(axial) 벡터이므로 부호 무시 축각($\arccos\lvert\cdot\rvert$)을 사용한다.
- 공면 거리는 "$j$의 중심이 $i$ 평면에서 벗어난 수직거리"와 그 반대를 **둘 다** 본다(대칭).

통과한 후보 간선을 **공면 거리 오름차순**(가장 평면적으로 일치하는 쌍부터)으로 정렬한다.
이 정렬 순서가 보고서의 연속성 항 $E_{con}$에 대응하는 역할을 한다(가장 신뢰도 높은 병합 우선).

### 2.2 2단계 — 증분 병합 + 두 하드 수용 검사

정렬된 간선을 순회하며 Union-Find로 병합을 **시도**한다. 이미 같은 군집이면 건너뛴다.
병합 후보 군집 $M = M_{r_i}\cup M_{r_j}$ 에 대해 **두 검사를 모두 통과**해야 병합을 확정한다.

**(a) 결합 평면 잔차 검사 — $E_{plane}$ 대응(군집 수준)**

병합된 모든 polyline 점 $\{p\}\in M$에 SVD 평면적합을 수행하고, RMS 잔차가 허용치 이하여야 한다.

$$ \mathrm{resid}(M)=\sqrt{\tfrac{1}{|M|}\sum_{p\in M}\big((p-\bar p)\!\cdot\!\hat n_M\big)^2}\ \le\ \varepsilon_{res}\quad(\text{기본 }0.08\ \text{m}). $$

**(b) "한 균열 = 면당 chord 1개" 물리제약 — $E_{con}$ 대응(핵심)**

하나의 원판형 균열은 한 막장면과 **오직 하나의 현(chord)**으로 교차한다. 따라서 병합 군집이
같은 면에 2개 이상의 멤버를 가지면, 그 중점들은 **현 방향과 수직인 면내 축**을 따라 좁게
모여 있어야 한다(=사실상 같은 현). 벌어져 있으면 서로 다른 균열이므로 병합을 기각한다.

- 현 방향 $\hat d = (\hat n_M \times \hat e_x)/\lVert\cdot\rVert$, 면내 수직축 $\hat u=\hat n_M\times\hat d$.
- 각 면에서 멤버 중점들의 $\hat u$ 투영 폭이 $\tau_{chord}$ 이하여야 한다.

$$ \forall\,\text{면 }f:\quad \max_{m\in M_f}(m\!\cdot\!\hat u)-\min_{m\in M_f}(m\!\cdot\!\hat u)\ \le\ \tau_{chord}\quad(\text{기본 }0.25\ \text{m}). $$

두 검사를 통과하면 병합을 확정하고 군집 멤버·법선을 갱신한다.

### 2.3 알고리즘 요약 (의사코드)

```
후보간선 E = { (i,j) : 게이트 2.1 통과 },  키 = 공면거리로 오름차순 정렬
for (i,j) in E:                      # 근접순
    M ← cluster(i) ∪ cluster(j)
    if resid(M) ≤ ε_res  AND  면당1chord(M) ≤ τ_chord:   # 두 하드검사
        merge(i, j)
```

## 3. 보고서 5개 항과 구현의 매핑

| 보고서 항(식 6.15) | 구현 대응 | 비고 |
|--------------------|-----------|------|
| $E_{plane}$ | (후보) 공면거리 $\le 0.15$m + (병합) SVD 잔차 $\le 0.08$m | 두 수준으로 분리 적용 |
| $E_{direction}$, $E_{normal}$ | 법선 축각 게이트 $\le 15°$ | 방향/법선 항이 하나의 축각 게이트로 통합 |
| $E_{con}$ (연속성) | 면당 1chord 제약 + 근접순 병합 | 가중항이 아니라 **하드 물리제약**으로 구현 |
| $E_{radius}$ | **연결 단계에 없음** | 반지름 타당성은 **복원 단계**(원적합 호커버리지·kr 축소추정)에서 판정 |
| 가중합 $S\le\tau$ | **미사용** | 스칼라 손실 대신 게이트+증분 하드검사 |

**요지 (미팅 설명 포인트)**
1. 손실은 튜닝 가중치 있는 단일 스칼라 $S$가 아니라, 물리 의미가 분명한 **하드 게이트 + 증분
   검증**이다. 자유 가중치가 없어 재현성·강건성이 높다.
2. $E_{radius}$는 **연결이 아니라 복원 단계**의 관심사다(연결은 평면·방향·연속성만 판단).
3. 병합 **순서(근접순)와 면당 1chord 제약**이 오연결(연쇄 병합)을 억제하는 핵심이며, 이것이
   보고서 연속성 개념의 실질적 구현이다.

## 4. 참고 — 대안 모드 (선택지)

구현에는 다음 4개 association 모드가 있다. 보고서의 "연속성 기반 매칭" 서술에 더 가까운 것은
`predictive`이다.

| 모드 | 방식 | 손실/판정 |
|------|------|-----------|
| `agglomerative`(기본) | 게이트 후 근접순 증분 병합 | 잔차 + 면당1chord 하드검사 |
| `geometric` | 단순 Union-Find | 게이트(축각·공면·근접)만, 검증 없음 |
| `predictive` | 면 간 chord 위치 예측 + 인접(±gap)면 **1:1 Hungarian 최적매칭** | 예측 chord선까지 수직거리 최소화(연속성 명시) |
| `oracle` | 참 fracture_id 로 묶음 | 검증 전용 |

`predictive`는 한 면의 절리선으로 다음 면의 chord 위치를 기하적으로 예측하고
($\hat d = \hat n\times\hat e_x$ 방향, 교선의 $x$-이동을 선형 모델로) 예측선까지의 수직거리를
비용으로 두어 면 간 1:1 매칭한다. 보고서의 "이격의 선형성·위치 연속성"을 명시적으로 쓰므로,
미팅에서 식 6.15의 $E_{con}$을 실제 수식으로 보이려면 `predictive`의 예측식을 병기하는 것이 좋다.

$$ q_b = m_a + \frac{x_b-x_{a}}{g_x}\,g,\quad g=\hat e_x-(\hat e_x\!\cdot\!\hat n_a)\hat n_a,\quad
\text{비용}=\big\lVert (m_b-q_b)-((m_b-q_b)\!\cdot\!\hat d)\hat d\big\rVert. $$
