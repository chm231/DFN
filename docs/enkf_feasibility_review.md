### 2.1 `Radius` 열은 새 정보가 아니다

미사용 열이라 독립 크기정보인지 확인했다. 12개 면 전체 6,447행:

```
Radius 중앙 0.138 m,  절리선 길이 중앙 0.292 m
Radius / 절리선길이 : 중앙 0.496  p5 0.368  p95 0.569
corr(Radius, 절리선 길이) = 0.9909
```

**절리선 길이의 절반**이다. `3D_README.txt` 도 filled disk 를 "lightweight triangular
fan surfaces from center/radius/normal", 즉 **시각화용 원판**이라고 명시한다.
실제 균열 반지름의 추정치가 아니다. → 동화할 새 정보 없음.

### 2.2 블라인드 검증의 "정답"은 관측이 아니다

`validate_blind_f06_l05.py` 는 1~6면 예측 확률장을 7~12면 기반 블록과 대조한다.
그러나 그 "정답" 블록은 **후속 면의 절리선에서 복원한 원판으로 만든 모델 산출물**이지
현장에서 관측된 블록이 아니다. 따라서 이를 동화해도 결국 절리선 정보를 재순환할 뿐이다.

## 3. 관측이 있다고 가정해도 — EnKF 가 최선이 아니다

### 3.1 상태가 15차원이다
set 3개 × (kr, P32, κ, trend, plunge) = 15.
EnKF 는 **칼만 게인을 정확히 계산할 수 없는 고차원**(기상 10⁷~10⁹, 저류층 10⁵~10⁶)에서
표본 공분산으로 근사하는 기법이다. 그 대가로 가우시안 가정과 spurious correlation 을
받아들이고 localization·inflation 으로 땜질한다.
15차원에서는 정확 베이즈(격자·SMC·MCMC)가 그냥 되므로 **근사 오차만 추가**된다.

### 3.2 우도를 이미 직접 계산하고 있다
kr 은 프로파일 우도 격자 탐색(hybrid: 해석식 길이분포 + kr불변 창커널),
P32 는 해석식 보정계수(`analytic_esinphi`). 둘 다 4면 기준 합계 2.0초다.
우도를 직접 쓸 수 있으면 앙상블 근사를 쓸 이유가 없다.

### 3.3 순차 갱신은 이미 정확하다 — 실측으로 확인됨
`worklog 2026-09-17 §(7)`: 공통 좌표계(set 번호·bin 상한·터널축)를 고정하면
Σ_f logL_f(kr) = logL_batch(kr) 가 성립한다(잔차 = kr 격자 한 칸).
다항우도 `Σ counts·log prob` 가 counts 에 가법적이기 때문이다.
**순차 갱신에서 얻을 정확도 이득이 0 임을 실증했다.** EnKF 는 이보다 나을 수 없다.

## 4. 그렇다면 언제 EnKF 가 의미를 갖는가

조건 B·C·D 중 최소 둘이 충족될 때다. 구체적 시나리오:

### 4.1 실제 낙반 관측 + **역학 층**이 함께 갖춰지면 (B+C 충족)

> **중요**: 현재 모형은 낙반을 예측하지 못한다. `detect_blocks_from_domain_json`
> 경로가 내놓는 것은 **기하학적 제거가능 블록**(절리평면 + 터널면으로 닫히고
> 도메인 외곽에 안 닿는 암괴)이다. 260903 전달본 README 에 명시돼 있듯
> "마찰각·활동력 등 운동학·역학 판정은 포함하지 않았다(한양대 소관)".

기하 블록 → 실제 낙반 사이에 빠진 층:

| 층 | 내용 | 현재 |
|---|---|---|
| ① 기하 | 블록이 닫히는가, 외곽 비접촉인가 | 구현됨 |
| ② 운동학 | 빠져나올 방향이 있는가(removability·활동 모드) | 없음 |
| ③ 역학 | 마찰각·점착력·중력·지압으로 실제 미끄러지는가 | 없음 |
| ④ 지보·시공 | 록볼트·숏크리트, 발파 손상, 굴착 순서 | 없음 |

격차는 실측됐다. 같은 20장 무한평면 입력에 대해 **기하 판정은 쐐기 100 % 발생,
한양대 도구(운동학·마찰 포함)는 0건**이었다(260903). 즉 기하 블록 수 ≫ 실제 낙반 수다.

**지금 상태로 낙반을 동화하면 안 된다.** 빠진 ②③④ 의 책임을 DFN 파라미터가
뒤집어쓴다 — 모형이 100개 예측하고 실제 3개면 동화는 "균열이 너무 많다"고 판단해
kr 을 올리거나 P32 를 낮추지만, 진짜 원인은 마찰로 안 떨어진 것이다.
전형적인 모형 오설정 흡수(model error absorption)다.

여굴은 더 멀다. 발파 과천공·과장약, 지질 약대, 블록 탈락이 섞인 결과라
DFN 만으로 예측할 대상이 아니다.

**역학 층을 붙이면** 비로소 성립한다:
```
상태 = DFN 파라미터(kr, P32, κ, trend, plunge) + 마찰각 + 점착력 + 지압
관측 = 실제 낙반 위치·규모
```
마찰각·점착력·지압은 원래 잘 모르는 값이라 낙반에서 역산하는 것이 정당하다.
이 관측연산자(DFN + 역학 → 낙반)는 우도를 직접 쓸 수 없을 만큼 복잡하므로
**그때 앙상블 방법이 실질적 대안이 된다.**

- 전방 모형 비용(기하 부분만): 조건부 DFN 생성 4~12초 + edge-cut 판정 8초 ≈ 실현당 15초.
  역학 층 비용은 미지.
- **계산 타당성**: ES-MDA 4회 동화 × 앙상블 50 = 200 forward → 8병렬 약 6~7분
  (기하 부분 기준). 계산은 제약이 아니다.
- 상태 15차원(+역학 파라미터) < 앙상블 50 이므로 localization 불필요, inflation 만 조정
- 권장은 **EnKF 가 아니라 ES-MDA** — 관측연산자가 강한 비선형이고 반복 동화가 더 강건하다.
- 다만 역학 층은 현재 분담상 한양대 소관이고 구현 규모가 크다.

### 4.2 상태를 고차원으로 재정의하면 (D 충족)
개별 균열의 중심·법선·반지름을 상태에 넣는 방안. **권하지 않는다.**
- 균열 개수가 멤버마다 달라 상태 차원이 가변
- 존재/부재가 이산·조합적이라 가우시안 가정과 정면 충돌
- 이미 하드 컨디셔닝(관측면에 절리선을 남겼을 균열 제거)으로 더 엄밀하게 처리 중

## 5. EnKF 대신 지금 할 가치가 있는 것

`worklog 2026-09-17 §(8)` 에서 측정된 **면 간 관측 상관**이 훨씬 큰 문제다.

- 다면 관통 원판 11.3 % 가 절리선 31.1 % 를 차지
- 위성 절리선(전체 24 %)이 짧은 구간에 몰려 단일창 전방 모형이 예측하지 못함
- **kr 이 중복 처리 방식에 따라 0.20~0.45 이동** — 창 간 변동(0.117)의 2~4배
- 방향은 전부 감소 → 현행은 큰 균열 과소평가(비안전측)

해법은 전방 모형을 **다면(평행 창 N개)으로 확장**하는 것이다. 모형 오설정을
직접 고치는 일이며, EnKF 를 얹는 것보다 추정 정확도에 미치는 영향이 크다.

## 7. 이 검토의 한계

- 자료 실사는 `demodata/DFM_Export` 한 현장에 한정했다. 다른 현장에 계측·낙반
  기록이 있다면 §2 의 결론이 바뀐다.
- 점군에서 여굴을 산출할 수 있는지는 **설계 단면 자료가 없어 확인하지 못했다**.
  설계 단면이 확보되면 여굴 형상이 유력한 동화 대상이 된다.
- §4.1 의 6~7분은 기존 실측(실현 4~12초, 판정 8초, 8병렬)에서 산정한 값이며
  실제 ES-MDA 를 돌려 측정한 것이 아니다.
- EnKF 계열 자체의 문헌적 판단(고차원 근사 도구)은 이 프로젝트 데이터로 검증한
  내용이 아니다. 다만 §3.3 의 "순차 갱신 이득 0" 은 실측이다.
